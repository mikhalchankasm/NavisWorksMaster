# Contributing

Build NavisHelper locally using the complete Navisworks 2024–2027 release matrix and MCP test commands in [CLAUDE.md — Build Commands](CLAUDE.md#build-commands). Installation prerequisites and runtime requirements are listed in [README.md — Requirements](README.md#requirements) and [README.md — Installation](README.md#installation).

Keep pull requests limited to one reviewable change and include the relevant build or test results.

This project is maintained at low activity. PRs are welcome; responses to issues are not guaranteed.
