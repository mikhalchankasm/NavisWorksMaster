# Contributing

Build NavisHelper locally using the complete Navisworks 2024–2027 release matrix and MCP test commands in [BUILD_BUNDLE_RULES.md — Команды сборки](BUILD_BUNDLE_RULES.md#команды-сборки). Installation prerequisites and runtime requirements are listed in [README.md — Requirements](README.md#requirements) and [README.md — Installation](README.md#installation).

Keep pull requests limited to one reviewable change and include the relevant build or test results. Agents working in this repository read [AGENTS.md](AGENTS.md) and nothing else before a task.

This project is maintained at low activity. PRs are welcome; responses to issues are not guaranteed.
