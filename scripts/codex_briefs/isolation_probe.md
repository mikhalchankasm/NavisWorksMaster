1. List every MCP server available to you, by name. If there are none, say
   "no MCP servers" explicitly.
2. List every MCP tool available to you, by name. If there are none, say
   "no MCP tools" explicitly.
3. List every built-in tool you can call that reaches the network, such as a web
   search or an image generator. If there are none, say "no network tools"
   explicitly.

   a file named .gitconfig exists next to it.
