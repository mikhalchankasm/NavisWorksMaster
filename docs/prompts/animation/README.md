# Готовые запросы: анимация облёта и видео

Пять сценариев для `viewpoint_animation` и `viewpoint_animation_export`. Каждый файл — готовый текст запроса к AI-агенту: скопируйте блок, замените значения в `<угловых скобках>` и вставьте в чат. Текст можно свободно менять под свою модель и задачу.

| Сценарий | Что получится | Файл |
| --- | --- | --- |
| Облёт вдоль трассы | вид на каждый прибор или элемент трассы, анимация с остановками, кадры или видео | [01-route-flythrough.md](01-route-flythrough.md) |
| Обход с подрезами | секущая рамка вокруг каждого элемента, вид сверху или изометрия, анимация | [02-section-tour.md](02-section-tour.md) |
| Проход по коллизиям | вид на каждую коллизию теста, анимация с паузой на каждой | [03-clash-walkthrough.md](03-clash-walkthrough.md) |
| Анимация из своих видов | анимация из уже сохранённых точек обзора в нужном порядке | [04-from-my-viewpoints.md](04-from-my-viewpoints.md) |
| Выгрузка и сжатие видео | PNG/JPG/AVI нужного качества и MP4 или GIF после сжатия | [05-export-video.md](05-export-video.md) |

Клиенты с поддержкой MCP-промптов (например, Claude Desktop и Claude Code) получают те же сценарии прямо из сервера NavisHelper, через `prompts/list`.

## Что нужно

- **Navisworks 2026 или 2027** для создания анимации: в 2024 и 2025 API не умеет её создавать.
- Группы инструментов `core,sections` (для коллизий ещё `clash`); профиль по умолчанию `all` их уже содержит. См. [MCP_CLIENT_GUIDE.md](../../MCP_CLIENT_GUIDE.md).
- Защищённый режим панели должен разрешать изменения: сценарии создают точки обзора и анимации.

## Как агент работает по этим сценариям

- Каждый шаг, который меняет документ, сначала идёт пробным прогоном (`apply=false`). Агент показывает план и делает запись только после вашего «да».
- Документ не сохраняется. Если результат нужен в файле модели, скажите об этом отдельно.
- Существующие точки обзора и анимации с тем же именем не перезаписываются без вашего согласия.
- Кадры пишутся в папку `viewpoint_animations\<имя анимации>` рядом с документом, если не указана другая.

## Пресеты качества

| Пресет | `width` × `height` | `fps` | `antiAliasLevel` | Для чего |
| --- | --- | --- | --- | --- |
| Черновик | 640 × 360 | 10 | 2 | быстро проверить маршрут и паузы |
| Для показа | 1280 × 720 | 25 | 4 | презентация, отправка коллегам после сжатия в MP4 |
| Высокое | 1920 × 1080 | 30 | 8 | большой экран; выгрузка заметно дольше |

Число кадров равно fps × длительность анимации: минута при 30 fps — это 1800 PNG. Пока идёт выгрузка, окно Navisworks не отвечает; сервер ждёт до 10 минут. Начинайте с черновика.

## Постобработка

Navisworks выгружает кадры PNG/JPG или AVI без сжатия: файлы большие. Для показа их сжимают в MP4 (H.264) или GIF. NavisHelper этого пока не делает. Агент с доступом к командной строке (Claude Code, Codex) может сделать это сам через [ffmpeg](https://ffmpeg.org/), если он установлен (на Windows: `winget install Gyan.FFmpeg`).

Команды для кадров `Flight1.png … FlightN.png`; подставьте своё имя анимации и fps выгрузки.

```text
MP4 из кадров:
ffmpeg -framerate 25 -i "Flight%d.png" -c:v libx264 -crf 23 -preset slow -pix_fmt yuv420p -movflags +faststart Flight.mp4

MP4 из AVI:
ffmpeg -i Flight.avi -c:v libx264 -crf 23 -preset slow -pix_fmt yuv420p -movflags +faststart Flight.mp4

Меньше файл: -crf 28 вместо 23, или уменьшить кадр: -vf "scale=1280:-2"

GIF-превью шириной 640 и 10 кадров в секунду:
ffmpeg -framerate 25 -i "Flight%d.png" -vf "fps=10,scale=640:-1:flags=lanczos,split[a][b];[a]palettegen[p];[b][p]paletteuse" Flight.gif
```

`-pix_fmt yuv420p` нужен, чтобы MP4 открывался в стандартных плеерах Windows и в браузере. После сжатия кадры можно удалить, но только после того, как вы проверили видео.
