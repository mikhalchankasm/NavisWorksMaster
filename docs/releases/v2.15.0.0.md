# NavisHelper 2.15.0.0

Обновление после [2.14.0.0](https://github.com/mikhalchankasm/NavisWorksMaster/releases/tag/v2.14.0.0). Главное:
- **покраска модели:** правило может менять только прозрачность, не трогая цвет; пути в правилах можно копировать из превью;
- **коллизии:** комментарии результатов можно прочитать, а у новых тестов выбрать, что проверять: грани, линии или точки;
- **список инструментов стал ещё короче:** 185 КБ вместо 197.

MCP-инструментов по-прежнему **117**.

## Какой файл скачать

| Файл | Кому нужен |
| --- | --- |
| **`NavisHelperSetup-2.15.0.0.exe`** | **Всем, начните с него.** Ставит плагин для Navisworks 2024–2027 и подключает к нему AI-программы. Права администратора не нужны. |
| `NavisHelper-2.15.0.0.mcpb` | Только пользователям **Claude Desktop**, если EXE не ставили: Claude Desktop → **Settings → Extensions**, установка из файла. Тот же файл EXE кладёт под именем `NavisHelper.mcpb` в папку, которую открывает ярлык «Расширение NavisHelper для Claude Desktop». |
| `NavisHelper-full-win-x64-framework-dependent-2.15.0.0.zip` | Для установки без EXE: вручную или AI-агентом, скриптом `Install-NavisHelperBundle.ps1` из архива. |
| `SHA256SUMS.txt`, `release-receipt.json` | Для проверки, что файлы не повреждены. В `release-receipt.json` указан коммит, из которого они собраны, и хэши DLL плагина. Обычной установке не нужны. |

Перед установкой закройте Navisworks. Нужен .NET 9 Runtime: если его нет, установщик предложит открыть страницу загрузки Microsoft.

## Что нового

### Покраска модели (`model_color_scheme`)

- **Только прозрачность.** Правилу достаточно `transparency`, без `colorHex`: элементы становятся полупрозрачными и сохраняют свой цвет. Так делают прозрачными изоляцию или зоны обслуживания оборудования, не перекрашивая их ([#339](https://github.com/mikhalchankasm/NavisWorksMaster/issues/339)).
- **Пути из превью.** `pathContains` принимает путь в том виде, в каком его показывает `find_items`, с разделителем ` / `. Раньше такой шаблон ничего не находил: внутри путь склеивается через `/`.
- **Одна транзакция.** Каждое применение и каждый `reset` выполняются одной транзакцией Navisworks.

### Коллизии

- **Комментарии.** `clash_list_results` с `includeComments=true` возвращает до 20 последних комментариев каждого результата: текст, автор, статус и время. Служебные пометки NavisHelper не показываются. В интерфейсе Navisworks удобно видно только последний комментарий.
- **Что проверять.** `clash_tests_from_sets` принимает `primitiveTypesA` и `primitiveTypesB`: `triangles`, `lines`, `points`. Это нужно, например, для осевых линий труб из RVM и облаков точек. Пустое значение оставляет настройку Navisworks по умолчанию.

### Меньше токенов

Описания инструментов `clash_*` переписаны короче, без потери сведений: список инструментов уменьшился ещё на 12 КБ, до 185 КБ, около 54 900 токенов.

### Руководство

Новый раздел о покраске модели: правила, прозрачность, формат пути, покраска большой модели порциями с `mode=accumulate`. Добавлено, как читать комментарии коллизий, запускать выбранные тесты и выбирать типы примитивов.

## Как обновиться

1. Закройте Navisworks и AI-программы (Claude Code, Codex, Cursor и другие).
2. Установите одним из способов:
   - **EXE:** запустите `NavisHelperSetup-2.15.0.0.exe` и оставьте флажок подключения AI-программ включённым;
   - **ZIP:** распакуйте архив и выполните `powershell -ExecutionPolicy Bypass -File .\Install-NavisHelperBundle.ps1 -ConfigureMcp`.
3. Запустите AI-программы и попросите агента вызвать `mcp_diagnostics`: он должен показать `mcpServerVersion: 2.15.0.0`. Если видна `2.14.0.0`, программа запустила старый сервер: закройте её полностью и запустите снова.
4. **Claude Desktop:** поставьте новое расширение через **Settings → Extensions** и перезапустите Desktop. Файл расширения — `NavisHelper.mcpb` из папки, которую открывает ярлык «Расширение NavisHelper для Claude Desktop», или скачанный `NavisHelper-2.15.0.0.mcpb`. Без этого шага Desktop останется на прежней версии.
   - Если в **Settings → Developer** осталась запись NavisHelper, запустите после установки расширения ярлык **«Подключить NavisHelper к AI-программам»** ещё раз: старая запись убирается, только когда расширение уже установлено.

Прежний сервер остаётся в хранилище версий `%LOCALAPPDATA%\NavisHelper\versions`. Вернуться к нему можно в PowerShell:

```powershell
& "$env:LOCALAPPDATA\NavisHelper\McpConfigurator\NavisHelper.McpConfigurator.exe" --rollback-server
```

Затем перезапустите AI-программы. Откатывается только MCP-сервер: плагин Navisworks остаётся 2.15.0.0, а `mcp_health_check` сообщает о расхождении версий (статус `degraded`). Claude Desktop эта команда не откатывает: у расширения своя копия сервера.

## Что проверено

- **Сборка:** под Navisworks 2024, 2025, 2026 и 2027; полный набор тестов (2985); CI.
- **Вживую, Navisworks 2027, 21 октября 2026** ([итоги](https://github.com/mikhalchankasm/NavisWorksMaster/issues/351)), на демо-модели из 24 объектов:
  - правило только с прозрачностью и шаблоном пути `/ HVAC /` (в 2.13 он не находил ничего) нашло все 8 воздуховодов: они стали полупрозрачными и остались голубыми, `reset` вернул их как было;
  - новый тест коллизий только по точкам дал 0 результатов, тест по граням и линиям — те же 2, что и обычный; недопустимый тип `surfaces` отклонён с понятной ошибкой;
  - комментарий, добавленный к коллизии, читается через `includeComments`: текст, автор, статус и время; без флага комментарии не читаются.
- **Приёмка кандидата вживую:** установщик в тихом режиме обновил рабочую установку 2.14; `mcp_health_check` вернул `healthy` с сервером и плагином 2.15.0.0. Установщик и ZIP прошли сценарии сборки: чистая установка, обновление со старым сервером, удаление; сервер отдаёт 117 инструментов.
- **Только сборкой:** версии 2024–2026, без живого прогона.
- **Не проверено вживую:** отмена покраски через Ctrl+Z (транзакция), страницы мастера установщика в обычном режиме, установка расширения 2.15 в Claude Desktop.

## Ограничения

- AI worker и MCP-сервер, в том числе в `.mcpb`, требуют .NET 9 Runtime.
- Установщик не подписан. Windows может показать окно «Система Windows защитила ваш компьютер»: нажмите «Подробнее», затем «Выполнить в любом случае».
- Autodesk Interop берётся из установленного Navisworks.
- `selection_color_by_property` меняет постоянные цвета, которые `model_color_scheme reset` не отменяет.
- Схема `model_color_scheme` живёт, пока открыт документ в этом сеансе Navisworks: после перезапуска `reset` уже недоступен.
- Зоны коллизий строятся по точкам коллизий, а не по габаритам элементов. Сфера показывает место проблемы, а не весь пересекающийся объект.
- Выбор файла `zones.ifc` в дереве модели и поиск зон по свойству `ZoneId` работают средствами Navisworks. Отдельного окна для зон в панели NavisHelper нет.
- `clash_zones_export` анализирует не больше 50 000 результатов за прогон. При превышении он сообщает об этом и работает с первыми 50 000.
