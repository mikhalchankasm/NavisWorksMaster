# NavisHelper 2.21.0.0

Обновление после [2.20.0.0](https://github.com/mikhalchankasm/NavisWorksMaster/releases/tag/v2.20.0.0). Главное:
- **экспорт в Twinmotion и Unreal (Datasmith):** файл модели в `.udatasmith` через MCP и кнопкой в панели, в том числе файлы, сохранённые в Navisworks 2027;
- **экспорт FBX по элементам:** выбранные элементы или их потомки на заданной глубине, каждый в свой файл;
- **вкладка «Экспорт»** в панели, а вкладка «Модель» сгруппирована в цветные карточки;
- **исправления по аудиту:** поиск, очередь хоста, коллизии, точки обзора, «Сохранить как NWD 2018»;
- **ответы MCP помещаются в лимит клиента:** большие ответы листаются по объёму, рамки элементов выгружаются в CSV.

MCP-инструментов стало **133** (было 127): `start_datasmith_export`, `datasmith_export_status`, `start_fbx_export`, `fbx_export_status`, `cancel_fbx_export`, `selection_export_bounding_boxes`.

## Какой файл скачать

| Файл | Кому нужен |
| --- | --- |
| **`NavisHelperSetup-2.21.0.0.exe`** | **Всем, начните с него.** Ставит плагин для Navisworks 2024–2027 и подключает к нему AI-программы. Права администратора не нужны. |
| `NavisHelper-2.21.0.0.mcpb` | Только пользователям **Claude Desktop**, если EXE не ставили: Claude Desktop → **Settings → Desktop app → Extensions → Manage → Advanced settings → Install Extension…** (в старых версиях: Settings → Extensions). Тот же файл EXE кладёт под именем `NavisHelper.mcpb` в папку, которую открывает ярлык «Расширение NavisHelper для Claude Desktop». |
| `NavisHelper-full-win-x64-framework-dependent-2.21.0.0.zip` | Для установки без EXE: вручную или AI-агентом, скриптом `Install-NavisHelperBundle.ps1` из архива. |
| `SHA256SUMS.txt`, `release-receipt.json` | Для проверки, что файлы не повреждены. В `release-receipt.json` указан коммит, из которого они собраны, и хэши DLL плагина. Обычной установке не нужны. |

Перед установкой закройте Navisworks. Нужен .NET 9 Runtime: если его нет, установщик предложит открыть страницу загрузки Microsoft.

## Что нового

### Экспорт в Datasmith для Twinmotion и Unreal ([#440](https://github.com/mikhalchankasm/NavisWorksMaster/issues/440), [#478](https://github.com/mikhalchankasm/NavisWorksMaster/issues/478), [#483](https://github.com/mikhalchankasm/NavisWorksMaster/issues/483))

Экспортёр Datasmith от Epic принимает путь к файлу только в режиме Automation, а в окне Navisworks открывает свой диалог. Поэтому экспорт идёт в отдельном скрытом Navisworks, а ваш открытый документ не затрагивается.
- **MCP:** `start_datasmith_export` экспортирует **сохранённый** файл `.nwd`, `.nwf` или `.nwc` в `.udatasmith` и сразу возвращает `operationId`; `datasmith_export_status` показывает ход, коды выхода, размер файла и ошибку. Параметры: `mergeLevel`, `origin`, `includeMetadata`, `overwrite`, `timeoutSeconds`.
- **Панель:** карточка «Twinmotion (Datasmith)» на вкладке «Экспорт» экспортирует открытый сохранённый файл; путь выбирается в диалоге, есть кнопка «Отмена».
- **Файлы Navisworks 2027.** Экспортёр существует только до Navisworks 2026, а 2026 не открывает файлы, сохранённые в 2027. Если 2026 не смог открыть файл, а Navisworks 2027 установлен, скрытый 2027 сохраняет временную копию в формате 2026, экспортируется эта копия, затем она удаляется.
- Скрытые Navisworks работают внутри задания Windows, которое закрывается вместе с экспортом: «Отмена», таймаут и закрытие сервера завершают их все.

### Экспорт FBX по элементам ([#444](https://github.com/mikhalchankasm/NavisWorksMaster/issues/444))

Каждый элемент — в отдельный файл `NNN_<имя>.fbx`, например уровни, секции или установки.
- **MCP:** `start_fbx_export` берёт `matchHandles` из `find_items` или текущее выделение (`useSelection=true`) и глубину `depth` от 0 до 20 (0 — сами элементы, 1 — их дочерние и так далее). `fbx_export_status` показывает счётчики и последние файлы, `cancel_fbx_export` останавливает задание.
- **Панель:** секция «Экспорт списка в FBX» на вкладке «Экспорт»: список заполняется кнопкой «Добавить выбранные», глубина и папка задаются там же; есть ход и «Отмена».
- Скрытые элементы пропускаются, видимость после каждого элемента восстанавливается. Больше 5000 элементов и существующие файлы без `overwrite` отклоняются. Настройки FBX берутся из Options Editor → File Exporters → FBX.

### Вкладка «Экспорт» и новая вкладка «Модель» ([#476](https://github.com/mikhalchankasm/NavisWorksMaster/issues/476), [#486](https://github.com/mikhalchankasm/NavisWorksMaster/issues/486))

- Экспорты переехали на отдельную вкладку «Экспорт» сразу после «Модели»: «Сохранить как NWD 2018», «Сохранить иерархию», экспорт свойств в Excel, FBX и Datasmith — каждая группа в своей карточке.
- Кнопки вкладки «Модель» сгруппированы в четыре цветные карточки: навигация, выбор, сведения о выборе, импорт.
- Панель запоминает вкладку по названию, а не по номеру, поэтому новые вкладки больше не сдвигают выбор. После обновления с 2.20 откроется та же вкладка, что была.

### Исправления по аудиту ([#457](https://github.com/mikhalchankasm/NavisWorksMaster/issues/457)–[#463](https://github.com/mikhalchankasm/NavisWorksMaster/issues/463), [#466](https://github.com/mikhalchankasm/NavisWorksMaster/issues/466), [#475](https://github.com/mikhalchankasm/NavisWorksMaster/issues/475))

- **Очередь хоста:** запрос, который ещё ждал в очереди Navisworks, когда истёк таймаут, больше не выполняется позже: ответ `REQUEST_TIMEOUT` теперь значит «не выполнено».
- **Поиск:** `find_items` по всей модели учитывает условие `or` между условиями. `select_by_search` с областью-родителем находит совпадения и под совпавшим родителем.
- **Коллизии:** номер в начале имени группы, заданный вами, больше не склеивает две разные группы. Точка обзора «Базовый вид», которая создаётся первой при «Сформировать точки обзора», теперь сбрасывает и секущую рамку, и переопределения цвета.
- **Точки обзора:** сортировка не переставляет кадры внутри анимации. `folderPath` при создании, импорте и переносе видов ведёт только в папки: если сегмент пути — анимация, вызов отклоняется, а не дописывает в неё кадры.
- **«Сохранить как NWD 2018»** записывает отдельный файл, выбранный в диалоге (по умолчанию `<имя>_2018.nwd`), и не может перезаписать открытый файл.
- **AI-раскраска:** обмен с AI-воркером идёт в ASCII, поэтому кириллица и символы вроде «Ø» в именах больше не теряются.

### Ответы MCP в пределах лимита клиента ([#427](https://github.com/mikhalchankasm/NavisWorksMaster/issues/427))

- `selected_items_tree` листается по объёму ответа (до 80 000 байт на страницу) и сообщает `budgetTruncated` и `nextOffset`; элемент больше страницы отклоняется с `response_too_large` и подсказкой, что сократить.
- Кириллица в ответах больше не превращается в `\uXXXX`, поэтому ответы с русскими именами стали короче.
- **`selection_export_bounding_boxes`** пишет рамки выбранных элементов в CSV (UTF-8 для Excel) и отвечает короткой сводкой, сколько бы элементов ни было.

## Как обновиться

1. Закройте Navisworks и AI-программы (Claude Code, Codex, Cursor и другие).
2. Установите одним из способов:
   - **EXE:** запустите `NavisHelperSetup-2.21.0.0.exe` и оставьте флажок подключения AI-программ включённым;
   - **ZIP:** распакуйте архив и выполните `powershell -ExecutionPolicy Bypass -File .\Install-NavisHelperBundle.ps1 -ConfigureMcp`.
3. Запустите AI-программы и попросите агента вызвать `mcp_diagnostics`: он должен показать `mcpServerVersion: 2.21.0.0`. Если видна `2.20.0.0`, программа запустила старый сервер: закройте её полностью и запустите снова.
4. **Claude Desktop:** поставьте новое расширение (путь в таблице выше) и перезапустите Desktop. Без этого шага Desktop останется на прежней версии.
   - Если в **Settings → Developer** осталась запись NavisHelper, запустите после установки расширения ярлык **«Подключить NavisHelper к AI-программам»** ещё раз.

Прежний сервер остаётся в хранилище версий `%LOCALAPPDATA%\NavisHelper\versions`. Вернуться к нему можно в PowerShell:

```powershell
& "$env:LOCALAPPDATA\NavisHelper\McpConfigurator\NavisHelper.McpConfigurator.exe" --rollback-server
```

Затем перезапустите AI-программы. Откатывается только MCP-сервер: плагин Navisworks остаётся 2.21.0.0, а `mcp_health_check` сообщает о расхождении версий (статус `degraded`).

## Что проверено

- **Сборка:** под Navisworks 2024, 2025, 2026 и 2027; полный набор тестов (3584); CI.
- **Приёмка вживую, Navisworks 2027, 14–15 ноября 2026**, на копиях демо-модели и рабочей модели 40 МБ; документы не сохранялись:
  - **Datasmith через MCP:** файл 2018 — за 8 с напрямую; файл 2027 — за 22 с через копию 2026; таймаут на модели 40 МБ завершил оба скрытых Navisworks; копия, оставшаяся после прерывания, удалена следующим экспортом.
  - **Datasmith из панели:** экспорт открытого файла 2027; «Отмена» во время копирования завершила runner и оба скрытых Navisworks за секунду, файл не записан.
  - **FBX:** экспорт слоёв на глубине 1 (скрытый слой пропущен, видимость сохранена), выделения, повторные дескрипторы, отказы на неверный ввод, «Отмена» из панели.
  - **Исправления аудита:** таймаут очереди хоста, `or` в поиске, область-родитель (найдено и исправлено до релиза: условия не нормализовались, [#474](https://github.com/mikhalchankasm/NavisWorksMaster/pull/474)), кадры анимации при сортировке и в `folderPath`, «Сохранить как NWD 2018» на копии `.nwf`, «Базовый вид» после 8 переопределений и секущей рамки.
  - **Панель:** вкладки и карточки; старый файл настроек 2.20 открыл ту же вкладку; выбор вкладки сохраняется после перезапуска.
- **Только сборкой:** Navisworks 2024, 2025 и 2026 без живого прогона новых функций.
- **Не проверено вживую:** AI-раскраска с кириллицей на платном ключе ([#463](https://github.com/mikhalchankasm/NavisWorksMaster/issues/463)).

## Ограничения

- AI worker и MCP-сервер, в том числе в `.mcpb`, требуют .NET 9 Runtime.
- Установщик не подписан. Windows может показать окно «Система Windows защитила ваш компьютер»: нажмите «Подробнее», затем «Выполнить в любом случае».
- Autodesk Interop берётся из установленного Navisworks.
- **Datasmith:** нужен установленный Navisworks Manage 2026 и экспортёр Datasmith от Epic для него; для файлов 2027 — ещё Navisworks Manage 2027. Экспортируется сохранённый файл, а не несохранённые изменения. `.nwf` со ссылками на файлы 2027 и Navisworks Simulate не поддерживаются. Копия, оставшаяся после «Отмены», удаляется следующим экспортом, если ей больше суток.
- **FBX:** экспорт идёт в открытом Navisworks и занимает его окно на время задания; ход и «Отмена» доступны в панели и через `fbx_export_status`/`cancel_fbx_export`.
- Ограничения анимаций из 2.20 сохраняются ([#421](https://github.com/mikhalchankasm/NavisWorksMaster/issues/421), [#422](https://github.com/mikhalchankasm/NavisWorksMaster/issues/422)).
