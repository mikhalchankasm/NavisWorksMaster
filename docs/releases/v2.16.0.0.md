# NavisHelper 2.16.0.0

Обновление после [2.15.0.0](https://github.com/mikhalchankasm/NavisWorksMaster/releases/tag/v2.15.0.0). Главное:
- **профиль Appearance Profiler одним вызовом:** новый инструмент `appearance_profile_apply` применяет сохранённый профиль встроенным загрузчиком Navisworks.

MCP-инструментов стало **118**.

## Какой файл скачать

| Файл | Кому нужен |
| --- | --- |
| **`NavisHelperSetup-2.16.0.0.exe`** | **Всем, начните с него.** Ставит плагин для Navisworks 2024–2027 и подключает к нему AI-программы. Права администратора не нужны. |
| `NavisHelper-2.16.0.0.mcpb` | Только пользователям **Claude Desktop**, если EXE не ставили: Claude Desktop → **Settings → Extensions**, установка из файла. Тот же файл EXE кладёт под именем `NavisHelper.mcpb` в папку, которую открывает ярлык «Расширение NavisHelper для Claude Desktop». |
| `NavisHelper-full-win-x64-framework-dependent-2.16.0.0.zip` | Для установки без EXE: вручную или AI-агентом, скриптом `Install-NavisHelperBundle.ps1` из архива. |
| `SHA256SUMS.txt`, `release-receipt.json` | Для проверки, что файлы не повреждены. В `release-receipt.json` указан коммит, из которого они собраны, и хэши DLL плагина. Обычной установке не нужны. |

Перед установкой закройте Navisworks. Нужен .NET 9 Runtime: если его нет, установщик предложит открыть страницу загрузки Microsoft.

## Что нового

### Профиль Appearance Profiler одним вызовом (`appearance_profile_apply`)

Раньше профиль на 70 правил приходилось воспроизводить сотней вызовов покраски, на больших моделях это занимало около 20 минут. Теперь достаточно указать файл профиля, который сохраняет сам Appearance Profiler (`.xml`), — Navisworks применит его своим загрузчиком за секунды ([#339](https://github.com/mikhalchankasm/NavisWorksMaster/issues/339)).

- **Пробный прогон** показывает все правила: по свойству (категория, свойство, условие, значение), по набору, цвет, прозрачность в процентах и скрытие.
- **Проверка заранее.** Navisworks молча отбрасывает весь профиль, если не может прочитать хотя бы одно правило, и ничего не сообщает. Пробный прогон находит такие причины до применения: дробную прозрачность (она должна быть целым процентом 0–100), цвет `Sc*`, не совпадающий с RGB (иначе правило окрашивается в чёрный), неизвестный тип правила. С ними `apply` отказывает и называет правило.
- **Применение** идёт одним действием отмены (Ctrl+Z). Всё, что не попало ни под одно правило, затеняется, как в самом профайлере. Загрузчику передаётся копия ровно того файла, который прошёл проверку.

### Для разработки

- Исполнитель Codex теперь сам запускает тесты внутри своей песочницы ([#353](https://github.com/mikhalchankasm/NavisWorksMaster/pull/353)).

## Как обновиться

1. Закройте Navisworks и AI-программы (Claude Code, Codex, Cursor и другие).
2. Установите одним из способов:
   - **EXE:** запустите `NavisHelperSetup-2.16.0.0.exe` и оставьте флажок подключения AI-программ включённым;
   - **ZIP:** распакуйте архив и выполните `powershell -ExecutionPolicy Bypass -File .\Install-NavisHelperBundle.ps1 -ConfigureMcp`.
3. Запустите AI-программы и попросите агента вызвать `mcp_diagnostics`: он должен показать `mcpServerVersion: 2.16.0.0`. Если видна `2.15.0.0`, программа запустила старый сервер: закройте её полностью и запустите снова.
4. **Claude Desktop:** поставьте новое расширение через **Settings → Extensions** и перезапустите Desktop. Файл расширения — `NavisHelper.mcpb` из папки, которую открывает ярлык «Расширение NavisHelper для Claude Desktop», или скачанный `NavisHelper-2.16.0.0.mcpb`. Без этого шага Desktop останется на прежней версии.
   - Если в **Settings → Developer** осталась запись NavisHelper, запустите после установки расширения ярлык **«Подключить NavisHelper к AI-программам»** ещё раз: старая запись убирается, только когда расширение уже установлено.

Прежний сервер остаётся в хранилище версий `%LOCALAPPDATA%\NavisHelper\versions`. Вернуться к нему можно в PowerShell:

```powershell
& "$env:LOCALAPPDATA\NavisHelper\McpConfigurator\NavisHelper.McpConfigurator.exe" --rollback-server
```

Затем перезапустите AI-программы. Откатывается только MCP-сервер: плагин Navisworks остаётся 2.16.0.0, а `mcp_health_check` сообщает о расхождении версий (статус `degraded`). Claude Desktop эта команда не откатывает: у расширения своя копия сервера.

## Что проверено

- **Сборка:** под Navisworks 2024, 2025, 2026 и 2027; полный набор тестов (3000); CI.
- **Профиль вживую, Navisworks 2027 (русский интерфейс), 21 октября 2026**, на демо-модели ([итоги](https://github.com/mikhalchankasm/NavisWorksMaster/pull/354)): синтетический профиль применил все три правила (по свойству — красный с прозрачностью 30 %, по набору — синий, скрытие); копия с дробной прозрачностью отклонена с указанием правила; настоящий рабочий профиль (72 правила) прошёл пробный прогон без ошибок.
- **Приёмка кандидата вживую, 22 октября 2026:** установщик в тихом режиме обновил рабочую установку 2.15; `mcp_health_check` вернул `ok` с плагином 2.16.0.0. На демо-модели установленный `appearance_profile_apply` в пробном прогоне показал три правила без ошибок, затем применил их (красный с прозрачностью 30 %, синий по набору, скрытие). Копия с дробной прозрачностью отклонена до применения. Установщик прошёл сценарии сборки: чистая установка, обновление со старым сервером, удаление; сервер отдаёт 118 инструментов.
- **Только сборкой:** версии 2024–2026, без живого прогона; песочница исполнителя (#353) проверена пробным запуском владельца, а не в релизной сборке.
- **Не проверено вживую:** страницы мастера установщика в обычном режиме, установка расширения 2.16 в Claude Desktop.

## Ограничения

- AI worker и MCP-сервер, в том числе в `.mcpb`, требуют .NET 9 Runtime.
- Установщик не подписан. Windows может показать окно «Система Windows защитила ваш компьютер»: нажмите «Подробнее», затем «Выполнить в любом случае».
- Autodesk Interop берётся из установленного Navisworks.
- `selection_color_by_property` меняет постоянные цвета, которые `model_color_scheme reset` не отменяет.
- `appearance_profile_apply` применяет профиль встроенным загрузчиком Navisworks: отменяется одним Ctrl+Z, но не командой `model_color_scheme reset`. Всё, что не попало ни под одно правило, затеняется, как в самом профайлере.
- Схема `model_color_scheme` живёт, пока открыт документ в этом сеансе Navisworks: после перезапуска `reset` уже недоступен.
- Зоны коллизий строятся по точкам коллизий, а не по габаритам элементов. Сфера показывает место проблемы, а не весь пересекающийся объект.
- Выбор файла `zones.ifc` в дереве модели и поиск зон по свойству `ZoneId` работают средствами Navisworks. Отдельного окна для зон в панели NavisHelper нет.
- `clash_zones_export` анализирует не больше 50 000 результатов за прогон. При превышении он сообщает об этом и работает с первыми 50 000.
