# NavisHelper 2.11.0.0

Обновление после [2.10.0.0](https://github.com/mikhalchankasm/NavisWorksMaster/releases/tag/v2.10.0.0). Главное:
- **защищённый режим:** агент не изменит документ без вашего разрешения в панели;
- **установка MCP-сервера с откатом:** новая версия встаёт рядом со старой и включается только после проверки;
- **расширение для Claude Desktop.**

MCP-инструментов стало **113** вместо 111.

## Что нового

### Защищённый режим

По умолчанию выключен. Включается флажком **«Защищённый режим»** на вкладке настроек панели NavisHelper, в разделе «Доступ агентов к изменениям». Настройка сохраняется между запусками Navisworks.

Когда режим включён:
- **Чтение** (поиск, свойства, виды, статусы) работает как раньше.
- **Изменение документа без разрешения** агент не выполнит. Он получит отказ с кодом из четырёх цифр и попросит вас подтвердить этот код.
- **Запрос появляется в панели** в списке «Ожидающие запросы». Строка показывает клиента, метку его сеанса, файл и код, например `claude-code [3f9a1c] · model.nwd · Код: 4821`. Справа кнопки **«Разрешить»** и **«Отклонить»**. Не подтверждённый за 10 минут запрос пропадает.
- **Разрешение действует на один документ и один сеанс клиента.** Другой клиент или второй сеанс того же клиента запрашивает разрешение отдельно. Выданные разрешения видны в списке «Выданные разрешения», и любое можно **отозвать**.

| Что вы делаете | Разрешения и ожидающие запросы |
| --- | --- |
| Ctrl+S (сохранение под тем же именем) | остаются |
| «Сохранить как» в другое имя, открытие другого файла, «Создать», закрытие | сбрасываются |
| «Отозвать» в панели | сбрасывается одно разрешение |
| Выключение защищённого режима | сбрасываются все |

Защищённому режиму нужен MCP-сервер 2.11: он сообщает хосту, какой сеанс прислал запрос. Старый сервер с включённой защитой получит отказ с просьбой обновиться. Поэтому после обновления перезапустите MCP-клиентов.

### Установка MCP-сервера с откатом

- **Где лежит сервер.** Каждая версия ставится в отдельную папку `%LOCALAPPDATA%\NavisHelper\versions\<версия>-<хеш>`. Клиенты настраиваются на постоянный путь `%LOCALAPPDATA%\NavisHelper\McpServer\NavisHelper.McpServer.exe`, а он ссылается на текущую версию.
- **Как ставится новая версия.** Установщик её запускает и проверяет, затем переключает ссылку. Предыдущая версия остаётся для отката: `NavisHelper.McpConfigurator.exe --rollback-server`. Неиспользуемые старые версии удаляет `--prune-servers`.
- **Если установку прервали** посреди переключения, следующая установка доводит его до конца или возвращает прежнюю версию.
- **EXE и ZIP** ставят сервер одинаково. Сборка установщика, установка, обновление и удаление проверяются в CI.

### Claude Desktop

Claude Desktop при перезапуске стирал NavisHelper из своего конфига. Поэтому для него теперь есть расширение **`NavisHelper.mcpb`**: откройте его в Claude Desktop через **Settings → Extensions**. В настройках расширения можно включить режим только чтения и выбрать набор инструментов. Расширение несёт собственную копию сервера: при обновлении NavisHelper поставьте и новый `.mcpb`.

### Для агентов (MCP)

- Новые инструменты `get_view_display_settings` и `set_view_display_settings` читают и задают фон, освещение и стиль отображения.
- Инструменты помечены: какие только читают, какие меняют документ. Клиенты, которые понимают эти пометки, могут спрашивать подтверждение только на изменения.
- **При подключении:**
  - сервер передаёт агенту краткие правила работы;
  - список инструментов передаётся компактнее, сами инструменты не изменились.
- Каталог инструментов доступен как ресурсы `navishelper://catalog/tools`, есть готовые сценарии (prompts) для типовых задач.
- **Диагностика установки клиента:** `NavisHelper.McpConfigurator.exe --doctor --clients <клиент>`. Команда ничего не меняет.
- **Журналы:**
  - сервер пишет журнал только в stderr, а не в журнал событий Windows;
  - журнал вызовов показывает, какой клиент вызывал инструмент.
- MCP SDK обновлён до 2.2.

### Надёжность

- Ошибки, которые раньше молча пропадали (панель Clash, предпросмотр, прочие части плагина), теперь пишутся в журнал.
- Конфигуратор клиентов бережно правит чужие файлы: не трогает посторонние настройки (в том числе TOML Codex) и честно сообщает, если записать не удалось.

## Как обновиться

1. Закройте Navisworks и MCP-клиентов: Claude, Codex, Cursor и другие.
2. Установите одним из способов:
   - **EXE:** запустите `NavisHelperSetup-2.11.0.0.exe`;
   - **ZIP:** распакуйте архив и выполните `powershell -ExecutionPolicy Bypass -File .\Install-NavisHelperBundle.ps1 -ConfigureMcp`.
3. Перенастройте клиентов на новый путь сервера. Для EXE это ярлык **«Настроить обнаруженные MCP-клиенты»** в меню «Пуск»; для ZIP — флаг `-ConfigureMcp` из шага 2. **Claude Desktop** настраивается отдельно: установите `NavisHelper.mcpb`.
4. Запустите клиентов заново и проверьте связь инструментом `mcp_health_check`.

Если клиенты были настроены на `%LOCALAPPDATA%\NavisHelper\McpServer-2.10.0.0`, после перенастройки эта папка больше не нужна. Удалите её, когда ни один клиент её не использует.

## Что проверено

- **Сборка:** под Navisworks 2024, 2025, 2026 и 2027; полный набор тестов; CI.
- **Защищённый режим вживую на Navisworks 2027:** включение и сохранение настройки, разрешение, отклонение, отзыв для одного из двух клиентов, сброс при смене документа и «Сохранить как», выключение, перевод интерфейса.
- **ЧЕРНОВИК, до приёмки:** сохранение разрешений при Ctrl+S и метки сеансов будут проверены вживую при приёмке релиза (#271).
- **Только сборкой:** версии 2024–2026, без живого прогона.

## Ограничения

- AI worker и MCP-сервер в обычном пакете требуют .NET 9 Runtime.
- Установщик не подписан.
- Autodesk Interop берётся из установленного Navisworks.
- `selection_color_by_property` меняет постоянные цвета, которые `model_color_scheme reset` не отменяет.
