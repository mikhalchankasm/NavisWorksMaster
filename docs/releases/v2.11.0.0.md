# NavisHelper 2.11.0.0

Обновление после [2.10.0.0](https://github.com/mikhalchankasm/NavisWorksMaster/releases/tag/v2.10.0.0). Главное:
- **защищённый режим:** если его включить, агент не изменит документ без вашего разрешения в панели;
- **установка MCP-сервера с откатом:** новая версия ставится рядом со старой и включается только после проверки;
- **расширение для Claude Desktop.**

MCP-инструментов стало **113** вместо 111.

## Какой файл скачать

| Файл | Кому нужен |
| --- | --- |
| **`NavisHelperSetup-2.11.0.0.exe`** | **Всем, начните с него.** Ставит плагин для Navisworks 2024–2027 и MCP-сервер. Права администратора не нужны. |
| `NavisHelper-2.11.0.0.mcpb` | Только пользователям **Claude Desktop**. После установки EXE откройте Claude Desktop → **Settings → Extensions** и установите этот файл. |
| `NavisHelper-full-win-x64-framework-dependent-2.11.0.0.zip` | Для установки без EXE: вручную или AI-агентом, скриптом `Install-NavisHelperBundle.ps1` из архива. |
| `SHA256SUMS.txt`, `release-receipt.json` | Для проверки, что файлы не повреждены и собраны из коммита `8ac2bb0`. Обычной установке не нужны. |

Перед установкой закройте Navisworks. Нужен .NET 9 Runtime: если его нет, установщик предложит открыть страницу загрузки Microsoft.

## Что нового

### Защищённый режим

По умолчанию выключен. Включается флажком **«Защищённый режим»** на вкладке настроек панели NavisHelper, в разделе «Доступ агентов к изменениям». Настройка сохраняется между запусками Navisworks.

Когда режим включён:
- **Чтение** (поиск, свойства, виды, статусы) работает как раньше.
- **Изменение документа без разрешения** агент не выполнит. Он получит отказ с кодом из четырёх цифр и попросит вас подтвердить этот код.
- **Запрос появляется в панели** в списке «Ожидающие запросы». Строка показывает клиента, метку его сеанса, файл и код, например `claude-code [3f9a1c] · model.nwd · Код: 4821`. Справа кнопки **«Разрешить»** и **«Отклонить»**. Не подтверждённый за 10 минут запрос пропадает.
- **Разрешение действует на один документ и один сеанс клиента.** Другой клиент или второй сеанс того же клиента запрашивает разрешение отдельно. Выданные разрешения видны в списке «Выданные разрешения», и любое можно **отозвать**.

| Что вы делаете | Разрешения и ожидающие запросы |
| --- | --- |
| Ctrl+S (сохранение под тем же именем) | остаются |
| «Сохранить как» в другое имя, открытие другого файла, «Создать», закрытие | сбрасываются |
| «Отозвать» в панели | сбрасывается одно разрешение |
| Выключение защищённого режима | сбрасываются все |

Защищённому режиму нужен MCP-сервер 2.11: он сообщает хосту, какой сеанс прислал запрос. Старый сервер с включённой защитой получит отказ с просьбой обновиться. Поэтому после обновления перезапустите MCP-клиентов.

### Установка MCP-сервера с откатом

- **Где лежит сервер.** Каждая версия ставится в отдельную папку `%LOCALAPPDATA%\NavisHelper\versions\<версия>-<хеш>`. Клиенты настраиваются на постоянный путь `%LOCALAPPDATA%\NavisHelper\McpServer\NavisHelper.McpServer.exe`, а он ссылается на текущую версию.
- **Как ставится новая версия.** Установщик запускает её и запрашивает у неё список инструментов, затем переключает ссылку. Если проверка не прошла, остаётся прежняя версия.
- **Откат.** Предыдущая версия хранится для отката: `NavisHelper.McpConfigurator.exe --rollback-server`. Неиспользуемые старые версии удаляет `--prune-servers`.
  - **Первое обновление с 2.10 из ZIP откатить нельзя:** сервер 2.10 лежал в `McpServer-2.10.0.0`, вне хранилища версий. Эта папка не удаляется, на неё можно вручную вернуть клиентов.
  - **Сервер 2.10 из EXE** при первом обновлении переносится в хранилище и становится версией для отката.
- **Если установку прервали** посреди переключения, следующая установка доводит его до конца или возвращает прежнюю версию.
- **EXE и ZIP** ставят плагин и сервер в одни и те же папки, способ можно менять. Сборка установщика, установка, обновление и удаление проверяются в CI.

### Claude Desktop

Claude Desktop при перезапуске мог удалять NavisHelper из своего конфига (мы наблюдали это 12 октября 2026). Поэтому для него теперь есть расширение **`NavisHelper.mcpb`**: откройте его в Claude Desktop через **Settings → Extensions**.
- В настройках расширения можно включить режим только чтения и выбрать набор инструментов.
- Расширение несёт собственную копию сервера, ей тоже нужен .NET 9 Runtime. При обновлении NavisHelper поставьте и новый `.mcpb`.

### Для агентов (MCP)

- Новые инструменты `get_view_display_settings` и `set_view_display_settings` читают и задают фон, освещение и стиль отображения.
- Инструменты помечены: какие только читают, какие меняют документ. Клиенты, которые понимают эти пометки, могут спрашивать подтверждение только на изменения.
- **При подключении:**
  - сервер передаёт агенту краткие правила работы;
  - список инструментов передаётся компактнее, сами инструменты не изменились.
- Каталог инструментов активного профиля доступен как ресурсы `navishelper://catalog/tools`, есть готовые сценарии (prompts) для типовых задач.
- **Строже проверяются входные данные:** неверно заданные пути и ссылки в схемах теперь возвращают понятную ошибку, а не обрабатываются как попало.
- **Диагностика установки клиента:** `NavisHelper.McpConfigurator.exe --doctor --clients <клиент>`. Команда ничего не меняет. Она показывает, на какой сервер настроен клиент, и добавляет ограниченные сведения о запущенных процессах.
- **Журналы:**
  - сервер пишет журнал только в stderr, а не в журнал событий Windows;
  - журнал вызовов показывает, какой клиент вызывал инструмент.
- MCP SDK обновлён до 2.2.

### Надёжность и изменения поведения

- **Импорт атрибутов из CSV** сначала проверяет весь файл, включая кодировку. Файл с ошибкой в любой строке отклоняется целиком, а не импортируется частично.
- **AI в панели** больше не зависает, если обработчик перестал принимать данные: запрос отменяется.
- Ошибки, которые раньше молча пропадали (панель Clash, предпросмотр, прочие части плагина), теперь пишутся в журнал.
- Конфигуратор клиентов бережно правит чужие файлы: не трогает посторонние настройки (в том числе TOML Codex) и честно сообщает, если записать не удалось.

## Как обновиться

1. Закройте Navisworks и MCP-клиентов (Claude Code, Codex, Cursor и другие).
2. Установите одним из способов:
   - **EXE:** запустите `NavisHelperSetup-2.11.0.0.exe`;
   - **ZIP:** распакуйте архив и выполните `powershell -ExecutionPolicy Bypass -File .\Install-NavisHelperBundle.ps1 -ConfigureMcp`.
3. Перенастройте клиентов на новый путь сервера. Для EXE это ярлык **«Настроить обнаруженные MCP-клиенты»** в меню «Пуск»; для ZIP — флаг `-ConfigureMcp` из шага 2.
4. Запустите клиентов, кроме Claude Desktop, и проверьте, что они работают с новым сервером: инструмент `mcp_diagnostics` должен показать `mcpServerVersion: 2.11.0.0`. Если видна `2.10.0.0`, клиент запустил старый сервер: перенастройте его и перезапустите.
5. **Claude Desktop:**
   - откройте `NavisHelper.mcpb` через **Settings → Extensions** и перезапустите Desktop;
   - если в Desktop остался NavisHelper из конфига (**Settings → Developer**), удалите эту запись: расширения достаточно, а старая запись может запускать сервер 2.10;
   - проверьте `mcp_diagnostics` и в Desktop.

Если 2.10 ставилась из ZIP, после обновления останется папка `%LOCALAPPDATA%\NavisHelper\McpServer-2.10.0.0`. Это единственный способ вернуться на 2.10, поэтому удаляйте её, только когда убедитесь, что 2.11 работает. Удалять её можно после того, как все клиенты перезапущены и `mcp_diagnostics` у каждого показывает 2.11.0.0. Пока какой-то клиент держит старый сервер, удаление не пройдёт. У тех, кто ставил 2.10 через EXE, этой папки нет: старый сервер перенесён в хранилище версий.

## Что проверено

- **Сборка:** под Navisworks 2024, 2025, 2026 и 2027; полный набор тестов; CI.
- **Защищённый режим вживую на Navisworks 2027:** включение и сохранение настройки, разрешение, отклонение, отзыв для одного из двух клиентов, сброс при смене документа и «Сохранить как», выключение, перевод интерфейса.
- **Приёмка релиза вживую 14 октября 2026, Navisworks 2027** ([итоги](https://github.com/mikhalchankasm/NavisWorksMaster/issues/271#issuecomment-6169207234)):
  - обновление через `NavisHelperSetup-2.11.0.0.exe` поверх рабочей установки; Navisworks загрузил плагин 2.11.0.0, клиенты и расширение Claude Desktop работают с сервером 2.11.0.0;
  - Ctrl+S сохранил разрешение и ожидающий запрос, «Сохранить как» сбросил их;
  - два клиента различаются метками сеансов, «Отозвать» подействовал только на один.
- **Обновление в CI:**
  - EXE: поверх старого сервера в `McpServer`, в том числе при запущенном сервере;
  - ZIP: поверх `McpServer-<версия>`;
  - установка и удаление.
- **Только сборкой:** версии 2024–2026, без живого прогона.

## Ограничения

- AI worker и MCP-сервер, в том числе в `.mcpb`, требуют .NET 9 Runtime.
- Установщик не подписан.
- Autodesk Interop берётся из установленного Navisworks.
- `selection_color_by_property` меняет постоянные цвета, которые `model_color_scheme reset` не отменяет.
