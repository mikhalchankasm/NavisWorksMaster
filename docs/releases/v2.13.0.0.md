# NavisHelper 2.13.0.0

Обновление после [2.12.0.0](https://github.com/mikhalchankasm/NavisWorksMaster/releases/tag/v2.12.0.0). Главное:
- **зоны коллизий:** результаты Clash Detective превращаются в полупрозрачные сферы прямо в модели, с книгой Excel и сравнением итераций;
- **горячие клавиши панели** больше не перехватывают клавиатуру всего компьютера;
- **установщик** сам убирает устаревшую запись NavisHelper из Claude Desktop, если стоит расширение.

MCP-инструментов стало **117** вместо 115.

## Какой файл скачать

| Файл | Кому нужен |
| --- | --- |
| **`NavisHelperSetup-2.13.0.0.exe`** | **Всем, начните с него.** Ставит плагин для Navisworks 2024–2027 и подключает к нему AI-программы. Права администратора не нужны. |
| `NavisHelper-2.13.0.0.mcpb` | Только пользователям **Claude Desktop**, если EXE не ставили: Claude Desktop → **Settings → Extensions**, установка из файла. Тот же файл EXE кладёт в папку, которую открывает ярлык «Расширение NavisHelper для Claude Desktop». |
| `NavisHelper-full-win-x64-framework-dependent-2.13.0.0.zip` | Для установки без EXE: вручную или AI-агентом, скриптом `Install-NavisHelperBundle.ps1` из архива. |
| `SHA256SUMS.txt`, `release-receipt.json` | Для проверки, что файлы не повреждены. В `release-receipt.json` указан коммит, из которого они собраны, и хэши DLL плагина. Обычной установке не нужны. |

Перед установкой закройте Navisworks. Нужен .NET 9 Runtime: если его нет, установщик предложит открыть страницу загрузки Microsoft.

## Что нового

### Зоны коллизий: сферы в местах коллизий

Два новых инструмента показывают, где в модели находятся коллизии, и помогают следить за ними от одной версии модели к другой.

- **`clash_zones_export`** читает сохранённые результаты Clash Detective и собирает их в **зоны**:
  - сначала по паре объектов, затем по близости точек коллизий (по умолчанию 300 мм);
  - слишком длинные цепочки делятся на части радиусом до 3 м;
  - вокруг точек каждой зоны строится наименьшая сфера с запасом 100 мм, не меньше 150 мм;
  - режим `points` рисует сферу на каждую коллизию.

  Подтверждённый вызов записывает папку прогона рядом с моделью, `clash_zones\<идентификатор прогона>`:
  - `zones.json`: данные прогона;
  - `zones.xlsx`: листы «Run», «Zones», «Clashes» с числами в числовых ячейках;
  - `zones.ifc`: по одной полупрозрачной сфере на зону, с именем `Z-0001` и свойствами `NH_ClashZone` (зона, трек, число коллизий, радиус, стороны).
- **`clash_zones_markers`** добавляет `zones.ifc` в открытую модель как отдельный файл. Им же можно заменить сферы прогоном другой итерации, убрать их или поменять прозрачность. Он трогает только модели с именем `zones.ifc`, а первую модель документа не удаляет никогда.
- **Сравнение итераций.** При повторном экспорте укажите папку прошлого прогона. Каждая зона получит трек и состояние:
  - новая — красная;
  - сохранилась — оранжевая;
  - сдвинулась — жёлтая;
  - исчезнувшие зоны рисуются серыми.

  Отдельная книга `clash_zones_compare_<прошлый>_<текущий>.xlsx` перечисляет совпадения, новые и исчезнувшие зоны. Совпадение ищется по элементам модели, а не по GUID коллизии: каждая итерация — это новая NWD.
- По умолчанию в зоны попадают коллизии со статусами New, Active и Reviewed. Approved и Resolved только считаются.
- Оба инструмента сначала показывают план, а меняют что-то только после подтверждения. Модель они не сохраняют. Сохранять ли её, решаете вы: NWF хранит ссылку на `zones.ifc`, NWD встраивает сферы.

### Горячие клавиши панели

Горячие клавиши NavisHelper (Ctrl+Q, Ctrl+W, Ctrl+E, Ctrl+M, Ctrl+цифры, Ctrl+Shift+P/H) слушают только окно Navisworks. Раньше перехватчик клавиатуры работал на весь компьютер. Если Navisworks был занят долгой операцией, ввод в других программах мог тормозить. А после нескольких таких задержек Windows молча отключала перехватчик, и горячие клавиши переставали работать.

### Установка и подключение

- Запуск подключения AI-программ (`--configure`, в том числе флажок установщика) убирает старую запись `navishelper` из конфига Claude Desktop, если расширение NavisHelper уже установлено. Перед изменением сохраняется резервная копия конфига. Раньше Claude Desktop мог запускать два сервера.

### Надёжность

- Ошибки, которые плагин раньше молча пропускал (инструменты маркеров, панель Clash, служба агента, настройки AI), теперь пишутся в журнал. Это помогает разбирать сбои.

## Как обновиться

1. Закройте Navisworks и AI-программы (Claude Code, Codex, Cursor и другие).
2. Установите одним из способов:
   - **EXE:** запустите `NavisHelperSetup-2.13.0.0.exe` и оставьте флажок подключения AI-программ включённым;
   - **ZIP:** распакуйте архив и выполните `powershell -ExecutionPolicy Bypass -File .\Install-NavisHelperBundle.ps1 -ConfigureMcp`.
3. Запустите AI-программы и попросите агента вызвать `mcp_diagnostics`: он должен показать `mcpServerVersion: 2.13.0.0`. Если видна `2.12.0.0`, программа запустила старый сервер: закройте её полностью и запустите снова.
4. **Claude Desktop:** поставьте новое расширение через **Settings → Extensions** и перезапустите Desktop. Файл расширения — `NavisHelper.mcpb` из папки, которую открывает ярлык «Расширение NavisHelper для Claude Desktop», или скачанный `NavisHelper-2.13.0.0.mcpb`. Без этого шага Desktop останется на прежней версии.

Прежний сервер остаётся в хранилище версий `%LOCALAPPDATA%\NavisHelper\versions`. Вернуться к нему можно в PowerShell:

```powershell
& "$env:LOCALAPPDATA\NavisHelper\McpConfigurator\NavisHelper.McpConfigurator.exe" --rollback-server
```

Затем перезапустите AI-программы. Откатывается только MCP-сервер: плагин Navisworks остаётся 2.13.0.0, а `mcp_health_check` сообщает о расхождении версий (статус `degraded`). Claude Desktop эта команда не откатывает: у расширения своя копия сервера.

## Ограничения

- AI worker и MCP-сервер, в том числе в `.mcpb`, требуют .NET 9 Runtime.
- Установщик не подписан. Windows может показать окно «Система Windows защитила ваш компьютер»: нажмите «Подробнее», затем «Выполнить в любом случае».
- Autodesk Interop берётся из установленного Navisworks.
- `selection_color_by_property` меняет постоянные цвета, которые `model_color_scheme reset` не отменяет.
- Зоны коллизий строятся по точкам коллизий, а не по габаритам элементов. Сфера показывает место проблемы, а не весь пересекающийся объект.
- Выбор файла `zones.ifc` в дереве модели и поиск зон по свойству `ZoneId` работают средствами Navisworks. Отдельного окна для зон в панели NavisHelper нет.
- `clash_zones_export` анализирует не больше 50 000 результатов за прогон. При превышении он сообщает об этом и работает с первыми 50 000.
