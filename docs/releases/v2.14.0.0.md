# NavisHelper 2.14.0.0

Обновление после [2.13.0.0](https://github.com/mikhalchankasm/NavisWorksMaster/releases/tag/v2.13.0.0). Главное:
- **покраска модели порциями:** повторный `model_color_scheme` больше не отменяет молча предыдущий, а новый режим `accumulate` складывает порции;
- **список инструментов короче** на 13 КБ, около 3 900 токенов в каждой сессии.

MCP-инструментов по-прежнему **117**.

## Какой файл скачать

| Файл | Кому нужен |
| --- | --- |
| **`NavisHelperSetup-2.14.0.0.exe`** | **Всем, начните с него.** Ставит плагин для Navisworks 2024–2027 и подключает к нему AI-программы. Права администратора не нужны. |
| `NavisHelper-2.14.0.0.mcpb` | Только пользователям **Claude Desktop**, если EXE не ставили: Claude Desktop → **Settings → Extensions**, установка из файла. Тот же файл EXE кладёт под именем `NavisHelper.mcpb` в папку, которую открывает ярлык «Расширение NavisHelper для Claude Desktop». |
| `NavisHelper-full-win-x64-framework-dependent-2.14.0.0.zip` | Для установки без EXE: вручную или AI-агентом, скриптом `Install-NavisHelperBundle.ps1` из архива. |
| `SHA256SUMS.txt`, `release-receipt.json` | Для проверки, что файлы не повреждены. В `release-receipt.json` указан коммит, из которого они собраны, и хэши DLL плагина. Обычной установке не нужны. |

Перед установкой закройте Navisworks. Нужен .NET 9 Runtime: если его нет, установщик предложит открыть страницу загрузки Microsoft.

## Что нового

### Покраска модели порциями (`model_color_scheme`)

**Исправлено:** повторный `apply` молча отменял предыдущий. Раньше каждый вызов сначала возвращал всё, что перекрасил прошлый, и только потом красил свою порцию, а ответ выглядел как полный успех. Если красить большую модель частями, оставалась только последняя порция ([#338](https://github.com/mikhalchankasm/NavisWorksMaster/issues/338)).

- **Новый параметр `mode`:**
  - `replace` (по умолчанию) работает как раньше: прежняя схема снимается, новая применяется. Теперь ответ об этом сообщает: `previousSchemeRestored`, `restoredItemCount` и предупреждение. Пробный прогон предупреждает заранее.
  - `accumulate` добавляет новую порцию к активной схеме. Одна команда `reset` снимает всё накопленное и возвращает модели исходные цвета, даже если элемент перекрашивали несколько раз.
- В ответе есть `activeSchemeItemCount`: сколько элементов сейчас в схеме.

### Меньше токенов на список инструментов

Описания параметров `instanceId` и `navisworksVersion` повторялись почти в каждом инструменте. Теперь они объяснены один раз в инструкциях сервера, а список инструментов (`tools/list`) стал меньше на 13 КБ, примерно на 3 900 токенов ([#336](https://github.com/mikhalchankasm/NavisWorksMaster/issues/336)).

## Как обновиться

1. Закройте Navisworks и AI-программы (Claude Code, Codex, Cursor и другие).
2. Установите одним из способов:
   - **EXE:** запустите `NavisHelperSetup-2.14.0.0.exe` и оставьте флажок подключения AI-программ включённым;
   - **ZIP:** распакуйте архив и выполните `powershell -ExecutionPolicy Bypass -File .\Install-NavisHelperBundle.ps1 -ConfigureMcp`.
3. Запустите AI-программы и попросите агента вызвать `mcp_diagnostics`: он должен показать `mcpServerVersion: 2.14.0.0`. Если видна `2.13.0.0`, программа запустила старый сервер: закройте её полностью и запустите снова.
4. **Claude Desktop:** поставьте новое расширение через **Settings → Extensions** и перезапустите Desktop. Файл расширения — `NavisHelper.mcpb` из папки, которую открывает ярлык «Расширение NavisHelper для Claude Desktop», или скачанный `NavisHelper-2.14.0.0.mcpb`. Без этого шага Desktop останется на прежней версии.
   - Если в **Settings → Developer** осталась запись NavisHelper, запустите после установки расширения ярлык **«Подключить NavisHelper к AI-программам»** ещё раз: старая запись убирается, только когда расширение уже установлено.

Прежний сервер остаётся в хранилище версий `%LOCALAPPDATA%\NavisHelper\versions`. Вернуться к нему можно в PowerShell:

```powershell
& "$env:LOCALAPPDATA\NavisHelper\McpConfigurator\NavisHelper.McpConfigurator.exe" --rollback-server
```

Затем перезапустите AI-программы. Откатывается только MCP-сервер: плагин Navisworks остаётся 2.14.0.0, а `mcp_health_check` сообщает о расхождении версий (статус `degraded`). Claude Desktop эта команда не откатывает: у расширения своя копия сервера.

## Что проверено

- **Сборка:** под Navisworks 2024, 2025, 2026 и 2027; полный набор тестов (2956); CI.
- **Покраска порциями:** тестами закреплены журнал исходных состояний («первый захват побеждает»), разбор `mode` и схема инструмента. Ревью нашло два дефекта, оба исправлены до слияния: устаревший счётчик после `reset` и частично записанная схема при сбое чтения цвета.
- **Покраска вживую, Navisworks 2027, 20 октября 2026** ([итоги](https://github.com/mikhalchankasm/NavisWorksMaster/issues/338)), на демо-модели из 24 объектов:
  - две порции `accumulate` сложились (8, затем 16 элементов), на снимке видны обе;
  - пробный прогон `replace` заранее предупредил, что снимет 16 элементов; `apply` снял их и сообщил `previousSchemeRestored` и `restoredItemCount: 16`;
  - `reset` вернул исходные цвета;
  - элементы, перекрашенные дважды в режиме `accumulate`, после `reset` вернулись к исходному цвету: снимок совпал с исходным побайтно.
- **Приёмка кандидата вживую:** установщик в тихом режиме обновил рабочую установку 2.13; `mcp_health_check` вернул `healthy` с сервером и плагином 2.14.0.0. Установщик и ZIP прошли сценарии сборки: чистая установка, обновление со старым сервером, удаление; сервер отдаёт 117 инструментов.
- **Только сборкой:** версии 2024–2026, без живого прогона.
- **Не проверено вживую:** страницы мастера установщика в обычном режиме, установка расширения 2.14 в Claude Desktop, откат сервера `--rollback-server`.

## Ограничения

- AI worker и MCP-сервер, в том числе в `.mcpb`, требуют .NET 9 Runtime.
- Установщик не подписан. Windows может показать окно «Система Windows защитила ваш компьютер»: нажмите «Подробнее», затем «Выполнить в любом случае».
- Autodesk Interop берётся из установленного Navisworks.
- `selection_color_by_property` меняет постоянные цвета, которые `model_color_scheme reset` не отменяет.
- Схема `model_color_scheme` живёт, пока открыт документ в этом сеансе Navisworks: после перезапуска `reset` уже недоступен.
- Зоны коллизий строятся по точкам коллизий, а не по габаритам элементов. Сфера показывает место проблемы, а не весь пересекающийся объект.
- Выбор файла `zones.ifc` в дереве модели и поиск зон по свойству `ZoneId` работают средствами Navisworks. Отдельного окна для зон в панели NavisHelper нет.
- `clash_zones_export` анализирует не больше 50 000 результатов за прогон. При превышении он сообщает об этом и работает с первыми 50 000.
