# NavisHelper 2.20.0.0

Обновление после [2.19.0.0](https://github.com/mikhalchankasm/NavisWorksMaster/releases/tag/v2.19.0.0). Главное:
- **анимация облёта:** анимация Navisworks из сохранённых точек обзора, например вдоль трассы приборов, с паузами на повторных видах;
- **выгрузка анимации:** последовательность кадров PNG или JPG либо видео AVI из анимации одним вызовом;
- **готовые сценарии облёта:** пять сценариев прямо в сервере (MCP-промпты) и те же запросы в репозитории, чтобы скопировать и поправить под себя;
- **проверка JSON сечения:** `section_planes` отклоняет сечение чужого формата, а не применяет его молча.

MCP-инструментов стало **127** (было 125): `viewpoint_animation`, `viewpoint_animation_export`.

## Какой файл скачать

| Файл | Кому нужен |
| --- | --- |

| `NavisHelper-2.20.0.0.mcpb` | Только пользователям **Claude Desktop**, если EXE не ставили: Claude Desktop → **Settings → Extensions**, установка из файла. Тот же файл EXE кладёт под именем `NavisHelper.mcpb` в папку, которую открывает ярлык «Расширение NavisHelper для Claude Desktop». |
| `NavisHelper-full-win-x64-framework-dependent-2.20.0.0.zip` | Для установки без EXE: вручную или AI-агентом, скриптом `Install-NavisHelperBundle.ps1` из архива. |
| `SHA256SUMS.txt`, `release-receipt.json` | Для проверки, что файлы не повреждены. В `release-receipt.json` указан коммит, из которого они собраны, и хэши DLL плагина. Обычной установке не нужны. |

Перед установкой закройте Navisworks. Нужен .NET 9 Runtime: если его нет, установщик предложит открыть страницу загрузки Microsoft.

## Что нового

### Анимация облёта ([#403](https://github.com/mikhalchankasm/NavisWorksMaster/issues/403))

**`viewpoint_animation`** создаёт, показывает и удаляет анимации из сохранённых точек обзора. Раньше это делалось вручную в окне Saved Viewpoints.
- Кадры — копии точек обзора одной папки (в её порядке) или заданного списка. Каждый кадр сохраняет своё сечение, переопределённые цвета и пометки: при проигрывании видны и плоскости сечения, и пометки, а не только камера. Скрытые элементы кадр хранит, если в Navisworks включено сохранение скрытия в точках обзора (Save Hide/Required Attributes).
- Повтор той же камеры подряд становится паузой длиной `pauseSeconds` (по умолчанию 2 с). `holdSeconds` добавляет остановку в конце каждого участка. Паузы выдерживаются точно.
- `loops` и `smoothing` (`none`, `sync`, `spline`) задают повтор и сглаживание.
- По умолчанию пробный прогон: показывает план кадров и пауз и ничего не пишет.

Типичный путь: `viewpoints_per_item` на приборы трассы, затем `viewpoint_animation` с `sourceFolder` этой папки.

### Выгрузка анимации в кадры и видео ([#404](https://github.com/mikhalchankasm/NavisWorksMaster/issues/404), [#411](https://github.com/mikhalchankasm/NavisWorksMaster/issues/411))

**`viewpoint_animation_export`** выгружает сохранённую анимацию так же, как Animation → Export Animation.
- `format`: `png` или `jpg` (кадры `Имя_0001.png … Имя_0073.png`, номер дополнен нулями) либо `avi`. Число кадров равно fps × длительность анимации.
- `width`, `height`, `fps`, `antiAliasLevel` задают размер и частоту; 0 оставляет значения диалога.
- Папка по умолчанию — `viewpoint_animations\<имя анимации>` рядом с документом. Системные папки и папка установки NavisHelper отклоняются. Существующие кадры перезаписываются только с `overwrite=true`.
- Ответ — сводка: число файлов, общий размер, первый и последний файл, шаблон имени; формат проверяется по сигнатуре (`formatMatches`). Полный список файлов — по `listFiles=true`.
- Без `apply=true` инструмент только проверяет запрос и показывает настройки экспортёра.
- После вызова инструмент возвращает настройки диалога экспорта (размер, fps, папку и другие) и сообщает, что вернуть не удалось.

### Готовые сценарии облёта ([#418](https://github.com/mikhalchankasm/NavisWorksMaster/pull/418), [#419](https://github.com/mikhalchankasm/NavisWorksMaster/issues/419))

Пять сценариев: облёт вдоль трассы, обход узлов с подрезами, проход по коллизиям теста, анимация из своих видов, выгрузка и сжатие видео.
- **В сервере:** MCP-промпты `animation_route_flythrough`, `animation_section_tour`, `animation_clash_walkthrough`, `animation_from_viewpoints`, `animation_export_video`. В Claude Desktop и Claude Code они появляются в списке промптов. Каждый шаг, меняющий документ, агент сначала показывает пробным прогоном и выполняет после вашего подтверждения.
- **В репозитории:** [docs/prompts/animation](https://github.com/mikhalchankasm/NavisWorksMaster/tree/main/docs/prompts/animation) — те же запросы на русском и английском, пресеты качества (черновик, для показа, высокое) и команды ffmpeg для сжатия в MP4 и GIF.

### Проверка формата сечения ([#398](https://github.com/mikhalchankasm/NavisWorksMaster/issues/398))

`section_planes` читает сечение вида только если его JSON имеет тип `ClipPlaneSet` или `ClipPlane`, как пишет сам Navisworks. Сечение другого формата отклоняется с ошибкой, а не читается неверно.

## Как обновиться

1. Закройте Navisworks и AI-программы (Claude Code, Codex, Cursor и другие).
2. Установите одним из способов:
   - **EXE:** запустите `NavisHelperSetup-2.20.0.0.exe` и оставьте флажок подключения AI-программ включённым;
   - **ZIP:** распакуйте архив и выполните `powershell -ExecutionPolicy Bypass -File .\Install-NavisHelperBundle.ps1 -ConfigureMcp`.
3. Запустите AI-программы и попросите агента вызвать `mcp_diagnostics`: он должен показать `mcpServerVersion: 2.20.0.0`. Если видна `2.19.0.0`, программа запустила старый сервер: закройте её полностью и запустите снова.
4. **Claude Desktop:** поставьте новое расширение через **Settings → Extensions** и перезапустите Desktop. Файл расширения — `NavisHelper.mcpb` из папки, которую открывает ярлык «Расширение NavisHelper для Claude Desktop», или скачанный `NavisHelper-2.20.0.0.mcpb`. Без этого шага Desktop останется на прежней версии.
   - Если в **Settings → Developer** осталась запись NavisHelper, запустите после установки расширения ярлык **«Подключить NavisHelper к AI-программам»** ещё раз: старая запись убирается, только когда расширение уже установлено.

Прежний сервер остаётся в хранилище версий `%LOCALAPPDATA%\NavisHelper\versions`. Вернуться к нему можно в PowerShell:

```powershell
& "$env:LOCALAPPDATA\NavisHelper\McpConfigurator\NavisHelper.McpConfigurator.exe" --rollback-server
```

Затем перезапустите AI-программы. Откатывается только MCP-сервер: плагин Navisworks остаётся 2.20.0.0, а `mcp_health_check` сообщает о расхождении версий (статус `degraded`). Claude Desktop эта команда не откатывает: у расширения своя копия сервера.

## Что проверено

- **Сборка:** под Navisworks 2024, 2025, 2026 и 2027; полный набор тестов (3309); CI.
- **Приёмка вживую, Navisworks 2027, 28–29 октября 2026**, на демо-модели: маршрут из 6 точек обзора `viewpoints_per_item`.
  - **Анимация:** пробный прогон показал 12 кадров и 6 пауз и ничего не записал. Запись создала анимацию с теми же кадрами, повтором и сглаживанием. Повтор вида дал паузу. Совпадение имени отклонено, удаление трогает только эту анимацию. При проигрывании видны сечение и пометки каждого кадра (проверено вручную).
  - **Найдено и исправлено до релиза:** копии точек обзора сохраняли GUID оригинала, и запись падала на повторном GUID ([#407](https://github.com/mikhalchankasm/NavisWorksMaster/pull/407)).
  - **Выгрузка:** с одним `format` получены 73 кадра PNG и 73 кадра JPG 320×180 при 2 кадрах в секунду и файл AVI; при 10 кадрах в секунду — 360 кадров. Экспорт занял 0.2–4 с.
  - **Проверка на рабочей модели:** облёт по трассам большой модели (около 370 кадров на ролик). Найдено и исправлено до релиза: если имя анимации кончалось цифрой («v2»), кадры затирали друг друга (`v21` — и кадр 1, и кадр 21), а ответ на сотни кадров не помещался в лимит клиента ([#420](https://github.com/mikhalchankasm/NavisWorksMaster/issues/420)).
  - **Найдено и исправлено до релиза:** экспорт падал, пока в настройках диалога оставался рендерер «viewport» после опытов; формат PNG и JPG оказался адаптером, а не именем плагина. Теперь инструмент сам ставит формат и рендерер OpenGL ([#411](https://github.com/mikhalchankasm/NavisWorksMaster/issues/411)).
- **Только сборкой:** Navisworks 2024, 2025 и 2026 без живого прогона новых инструментов.
- **Не проверено вживую:** `get_item_texture_mapping` — ждёт модели с текстурами ([#377](https://github.com/mikhalchankasm/NavisWorksMaster/issues/377)).

## Ограничения

- AI worker и MCP-сервер, в том числе в `.mcpb`, требуют .NET 9 Runtime.
- Установщик не подписан. Windows может показать окно «Система Windows защитила ваш компьютер»: нажмите «Подробнее», затем «Выполнить в любом случае».
- Autodesk Interop берётся из установленного Navisworks.
- `viewpoint_animation` создаёт анимации только в Navisworks 2026 и 2027: в 2024 и 2025 API не даёт их создавать. Там пробный прогон показывает план с предупреждением, а `list` и `delete` работают.
- `viewpoint_animation_export` пишет AVI без сжатия, файлы большие; MP4 Navisworks не выгружает, кадры или AVI можно пережать сторонней программой.
- Экспорт блокирует окно Navisworks на время выгрузки; MCP ждёт его до 10 минут.
- `stepSeconds` в Navisworks 2027 не задаёт время перелёта: оно зависит от расстояния и поворотов камеры (например, вместо 7.7 с вышло 18 с). Паузы при этом точные. Точную длительность можно подогнать при сборке видео из кадров ([#421](https://github.com/mikhalchankasm/NavisWorksMaster/issues/421)).
- Если у соседних кадров разные нормали плоскости сечения, а модель далеко от начала координат, промежуточная плоскость проходит через всю сцену и кадры между ключами выходят почти пустыми. Внутри участка держите нормаль постоянной, а плоскость меняйте разрывом: два кадра с одной камерой. Плоскость с постоянной нормалью, например верхняя, меняет высоту плавно ([#422](https://github.com/mikhalchankasm/NavisWorksMaster/issues/422)).
- `pauseSeconds=0` не делает разрыв на повторной камере; для мгновенного разрыва задайте 0.04 ([#422](https://github.com/mikhalchankasm/NavisWorksMaster/issues/422)).
- Формат в настройках диалога Export Animation через API не меняется: после выгрузки в другом формате диалог предложит его. Прежняя текущая анимация с пустым именем тоже не восстанавливается. Оба случая инструмент сообщает предупреждением.
- `section_planes` и секущая рамка делят одно сечение вида: `set` плоскостей выключает рамку, а инструменты рамки — плоскости.
- `viewpoints_per_item` обрабатывает до 1000 элементов за вызов (по умолчанию 500). Элементы берутся как есть, без раскрытия вложенных.
- `get_item_texture_mapping` читает проекцию через внутренние классы Navisworks; на моделях с текстурами он вживую ещё не проверен.
- `reset_appearance` сбрасывает цвет и прозрачность, но не показывает скрытые элементы: скрытое шагом `hide` возвращают `show_all` или `unhide_selected`.
- `find_duplicate_geometry` сравнивает рамки и число примитивов, а не сами сетки: разные элементы одинаковых размеров в одном месте тоже попадут в группу.
- `appearance_profile_apply` применяет профиль встроенным загрузчиком Navisworks: отменяется одним Ctrl+Z, но не командой `model_color_scheme reset`.
- Схема `model_color_scheme` живёт, пока открыт документ в этом сеансе Navisworks: после перезапуска `reset` уже недоступен.
- Зоны коллизий строятся по точкам коллизий, а не по габаритам элементов. `clash_zones_export` анализирует не больше 50 000 результатов за прогон.
