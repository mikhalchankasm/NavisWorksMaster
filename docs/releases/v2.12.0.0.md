# NavisHelper 2.12.0.0

Обновление после [2.11.0.0](https://github.com/mikhalchankasm/NavisWorksMaster/releases/tag/v2.11.0.0). Главное:
- **установщик для обычных пользователей:** понятные тексты, подсказка «Что дальше» и расширение для Claude Desktop в комплекте;
- **проверки коллизий «одна марка против всех»** одним вызовом;
- **переименование групп коллизий и выбор результатов по имени**, без путаницы составов групп.

MCP-инструментов стало **115** вместо 113.

## Какой файл скачать

| Файл | Кому нужен |
| --- | --- |
| **`NavisHelperSetup-2.12.0.0.exe`** | **Всем, начните с него.** Ставит плагин для Navisworks 2024–2027 и подключает к нему AI-программы. Права администратора не нужны. |
| `NavisHelper-2.12.0.0.mcpb` | Только пользователям **Claude Desktop**, если EXE не ставили: Claude Desktop → **Settings → Extensions**, установка из файла. Тот же файл EXE кладёт в папку, которую открывает ярлык «Расширение NavisHelper для Claude Desktop». |
| `NavisHelper-full-win-x64-framework-dependent-2.12.0.0.zip` | Для установки без EXE: вручную или AI-агентом, скриптом `Install-NavisHelperBundle.ps1` из архива. |
| `SHA256SUMS.txt`, `release-receipt.json` | Для проверки, что файлы не повреждены и собраны из коммита `<sha>`. Обычной установке не нужны. |

Перед установкой закройте Navisworks. Нужен .NET 9 Runtime: если его нет, установщик предложит открыть страницу загрузки Microsoft.

## Что нового

### Установщик для обычных пользователей

- Тексты установщика написаны простым языком, без внутренних терминов.
- Флажок **«Подключить NavisHelper к AI-программам на этом компьютере (кроме Claude Desktop)»** на последней странице включён по умолчанию. Для Claude Desktop есть отдельное расширение.
- Установщик кладёт расширение `NavisHelper.mcpb` в свою папку. В меню «Пуск» появляется ярлык **«Расширение NavisHelper для Claude Desktop»**, который открывает эту папку.
- На последней странице есть короткая инструкция «Что дальше»: открыть Navisworks, перезапустить AI-программы после нажатия «Завершить», поставить расширение в Claude Desktop.

### Коллизии: одна марка против всех остальных

Новый инструмент `clash_one_vs_rest` создаёт проверки Clash Detective для одного узла дерева модели против каждого соседнего узла. Например, марка `/12470-14-1400/PI` против 24 других марок внутри одного RVM: одним вызовом получаются 24 проверки.
- Работает на любом уровне дерева, а не только для корневых файлов. Читает только выбранный узел и его соседей, поэтому не зависает на больших моделях.
- Для каждой стороны создаёт **явный Selection Set** в одной папке. Проверки на очередной версии модели проверяют те же элементы, что и раньше.
- По умолчанию без фильтров: тип Hard, допуск 1 мм. По желанию можно задать маски имён, отсев далёких узлов по габаритам и свой тип или допуск для отдельных пар.
- Режим `single` делает одну проверку: марка против всех остальных сразу.
- По умолчанию только показывает план. Создаёт проверки после подтверждения и сам их не запускает. Если набор или проверка с таким именем уже есть, сообщает об этом и ничего не перезаписывает без разрешения.

### Коллизии: группы и результаты

- Новый инструмент `clash_group_rename` переименовывает группы результатов по одной или пакетом. Состав групп и статусы не меняются. Перед изменением показывает план и не даёт получить две группы с одинаковым именем в одной папке.
- Результаты теперь можно выбирать **по имени** (`Конфликт3`) в `clash_group_custom` и `clash_set_status`. Раньше их выбирали только по номеру позиции в дереве теста, а позиции сдвигаются после каждой группировки. Поэтому несколько группировок подряд по одному списку могли разложить результаты не по тем группам. Выбор по имени от этого не зависит.
- Описания инструментов прямо предупреждают: номера результатов и групп — это позиции. После группировки список нужно получить заново.

### Панель

- В списке запросов защищённого режима кнопки **«Разрешить»** и **«Отклонить»** стоят рядом даже при длинном имени клиента.
- В окне «О программе» указан 2019–2026.

## Как обновиться

1. Закройте Navisworks и AI-программы (Claude Code, Codex, Cursor и другие).
2. Установите одним из способов:
   - **EXE:** запустите `NavisHelperSetup-2.12.0.0.exe` и оставьте флажок подключения AI-программ включённым;
   - **ZIP:** распакуйте архив и выполните `powershell -ExecutionPolicy Bypass -File .\Install-NavisHelperBundle.ps1 -ConfigureMcp`.
3. После установки перезапустите AI-программы. Инструмент `mcp_diagnostics` должен показать `mcpServerVersion: 2.12.0.0`.
4. **Claude Desktop:** поставьте новый `NavisHelper.mcpb` через **Settings → Extensions** и перезапустите Desktop. Расширение несёт свою копию сервера, поэтому без этого шага Desktop останется на прежней версии.
   - Если в **Settings → Developer** есть запись NavisHelper, удалите её: расширения достаточно.
   - ZIP с `-ConfigureMcp` снова добавляет эту запись, поэтому после него проверьте **Settings → Developer**.

Прежняя версия сервера остаётся в хранилище версий `%LOCALAPPDATA%\NavisHelper\versions`, к ней можно вернуться.

## Что проверено

- **Сборка:** под Navisworks 2024, 2025, 2026 и 2027; полный набор тестов; CI.
- **Новые инструменты вживую, Navisworks 2027, модель 12470, 15 октября 2026:**
  - `clash_one_vs_rest`: для `/12470-14-1400/PI` созданы 24 проверки на 25 наборах, все 24 посчитались ([итоги](https://github.com/mikhalchankasm/NavisWorksMaster/issues/282#issuecomment-6178909704));

Три группировки подряд по именам дали точные составы, а переименование не изменило ни составов, ни статусов ([итоги](https://github.com/mikhalchankasm/NavisWorksMaster/issues/285#issuecomment-6178910457)).
- **Приёмка релиза вживую:** <заполняется после приёмки>.
- **Только сборкой:** версии 2024–2026, без живого прогона.

## Ограничения

- AI worker и MCP-сервер, в том числе в `.mcpb`, требуют .NET 9 Runtime.
- Установщик не подписан.
- Autodesk Interop берётся из установленного Navisworks.
- `selection_color_by_property` меняет постоянные цвета, которые `model_color_scheme reset` не отменяет.
- Флажок «объединять составные объекты» в новых проверках `clash_one_vs_rest` не задаётся и остаётся таким, как по умолчанию в Navisworks.
