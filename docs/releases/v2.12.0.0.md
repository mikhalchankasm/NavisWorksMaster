# NavisHelper 2.12.0.0

Обновление после [2.11.0.0](https://github.com/mikhalchankasm/NavisWorksMaster/releases/tag/v2.11.0.0). Главное:
- **установщик для обычных пользователей:** понятные тексты, подсказка «Что дальше» и расширение для Claude Desktop в комплекте;
- **проверки коллизий «одна марка против всех»** одним вызовом;
- **переименование групп коллизий и выбор результатов по имени**, без путаницы составов групп.

MCP-инструментов стало **115** вместо 113.

## Какой файл скачать

| Файл | Кому нужен |
| --- | --- |
| **`NavisHelperSetup-2.12.0.0.exe`** | **Всем, начните с него.** Ставит плагин для Navisworks 2024–2027 и подключает к нему AI-программы. Права администратора не нужны. |
| `NavisHelper-2.12.0.0.mcpb` | Только пользователям **Claude Desktop**, если EXE не ставили: Claude Desktop → **Settings → Extensions**, установка из файла. Тот же файл EXE кладёт в папку, которую открывает ярлык «Расширение NavisHelper для Claude Desktop». |
| `NavisHelper-full-win-x64-framework-dependent-2.12.0.0.zip` | Для установки без EXE: вручную или AI-агентом, скриптом `Install-NavisHelperBundle.ps1` из архива. |
| `SHA256SUMS.txt`, `release-receipt.json` | Для проверки, что файлы не повреждены. В `release-receipt.json` указан коммит, из которого они собраны, и хэши DLL плагина. Обычной установке не нужны. |

Перед установкой закройте Navisworks. Нужен .NET 9 Runtime: если его нет, установщик предложит открыть страницу загрузки Microsoft.

## Что нового

### Установщик для обычных пользователей

- Тексты установщика написаны простым языком, без внутренних терминов.
- На последней странице флажок **«Подключить NavisHelper к AI-программам на этом компьютере (кроме Claude Desktop)»** включён по умолчанию. Он подключает Claude Code, Codex, Cursor, opencode, Kimi и ZCode. Другие программы подключите вручную.
- Если флажок сняли, подключить программы позже можно ярлыком **«Подключить NavisHelper к AI-программам»** в меню «Пуск».
- Установщик кладёт расширение `NavisHelper.mcpb` в подпапку `ClaudeDesktop` папки установки (по умолчанию `%LOCALAPPDATA%\NavisHelper\ClaudeDesktop`). Ярлык **«Расширение NavisHelper для Claude Desktop»** в меню «Пуск» открывает эту папку.
- На последней странице есть короткая инструкция «Что дальше»: открыть Navisworks, после нажатия «Завершить» перезапустить AI-программы, поставить расширение в Claude Desktop.

### Коллизии: одна марка против всех остальных

Новый инструмент `clash_one_vs_rest` создаёт проверки Clash Detective для одного узла дерева модели против каждого узла того же уровня. Например, марка `/12470-14-1400/PI` против 24 других марок внутри одного RVM: одним вызовом получаются 24 проверки.
- Работает на любом уровне дерева, а не только для корневых файлов. Читает только указанный узел и соседние узлы того же уровня, поэтому не обходит всю модель и быстро работает и на больших моделях.
- Для каждой стороны создаёт явный набор выбора (Selection Set) в одной папке. Состав набора фиксируется при создании. Подробнее — в разделе «Ограничения».
- По умолчанию без фильтров: тип Hard, допуск 1 мм. По желанию можно задать маски имён, отсев далёких узлов по габаритам и свой тип или допуск для отдельных пар.
- Режим `single` делает одну проверку: марка против всех остальных сразу.
- Первый вызов только показывает план. Наборы и проверки появляются после повторного вызова с подтверждением. Агент должен делать его только после вашего согласия; при включённом защищённом режиме запись дополнительно подтверждается в панели. Сами проверки инструмент не запускает.
- Если набор или проверка с таким именем уже есть, инструмент сообщает об этом и без `overwriteExisting=true` ничего не перезаписывает.

### Коллизии: группы и результаты

- Новый инструмент `clash_group_rename` переименовывает группы результатов проверки, по одной или пакетом. Состав групп и статусы не меняются. Перед изменением показывает план. Не даёт получить две группы с одинаковым именем на одном уровне проверки.
- Результаты теперь можно выбирать **по имени** в `clash_group_custom` и `clash_set_status`: например, `Конфликт3` (в английской версии Navisworks `Clash3`).
  - Раньше их выбирали только по номеру позиции в дереве проверки, а позиции сдвигаются после каждой группировки.
  - Поэтому несколько группировок подряд по одному списку могли разложить результаты не по тем группам.
  - Выбор по имени от этого не зависит.

### Панель

- В списке запросов защищённого режима кнопки **«Разрешить»** и **«Отклонить»** стоят рядом даже при длинном имени клиента.
- В окне «О программе» исправлены годы в строке авторских прав (© 2019–2026).

### Для агентов (MCP)

- Описания инструментов прямо предупреждают: номера результатов и групп коллизий — это позиции в дереве. После любой группировки список нужно получить заново или выбирать результаты по имени.

## Как обновиться

1. Закройте Navisworks и AI-программы (Claude Code, Codex, Cursor и другие).
2. Установите одним из способов:
   - **EXE:** запустите `NavisHelperSetup-2.12.0.0.exe` и оставьте флажок подключения AI-программ включённым;
   - **ZIP:** распакуйте архив и выполните `powershell -ExecutionPolicy Bypass -File .\Install-NavisHelperBundle.ps1 -ConfigureMcp`.
3. Запустите AI-программы и попросите агента вызвать `mcp_diagnostics`: он должен показать `mcpServerVersion: 2.12.0.0`. Если видна `2.11.0.0`, программа запустила старый сервер: закройте её полностью и запустите снова (для Claude Desktop — см. шаг 4).
4. **Claude Desktop:** поставьте новое расширение через **Settings → Extensions** и перезапустите Desktop. Файл расширения — `NavisHelper.mcpb` из папки, которую открывает ярлык «Расширение NavisHelper для Claude Desktop», или скачанный `NavisHelper-2.12.0.0.mcpb`. Расширение несёт свою копию сервера, поэтому без этого шага Desktop останется на прежней версии.
   - Если в **Settings → Developer** есть запись NavisHelper, удалите её: расширения достаточно.
   - ZIP с `-ConfigureMcp` снова добавляет эту запись. После него удалите её в **Settings → Developer**.

Если 2.12 ставили поверх прежней версии, прежний сервер остаётся в хранилище версий `%LOCALAPPDATA%\NavisHelper\versions`. Вернуться к нему можно в PowerShell:

```powershell
& "$env:LOCALAPPDATA\NavisHelper\McpConfigurator\NavisHelper.McpConfigurator.exe" --rollback-server
```

Затем перезапустите AI-программы. Откатывается только MCP-сервер: плагин Navisworks остаётся 2.12.0.0, а `mcp_health_check` сообщает о расхождении версий (статус `degraded`). Claude Desktop эта команда не откатывает: у расширения своя копия сервера.

## Что проверено

- **Сборка:** под Navisworks 2024, 2025, 2026 и 2027; полный набор тестов; CI.
- **Новые инструменты вживую, Navisworks 2027, модель 12470, 15 октября 2026:**
  - `clash_one_vs_rest`: для `/12470-14-1400/PI` созданы 24 проверки на 25 наборах, затем все 24 запущены отдельной командой запуска проверок ([итоги](https://github.com/mikhalchankasm/NavisWorksMaster/issues/282#issuecomment-6178909704));
  - выбор результатов по имени и `clash_group_rename`: воспроизведена прежняя путаница с номерами. Три группировки подряд по именам дали ожидаемые составы, а переименование не изменило ни составов, ни статусов ([итоги](https://github.com/mikhalchankasm/NavisWorksMaster/issues/285#issuecomment-6178910457)).
- **Приёмка релиза вживую 15 октября 2026, Navisworks 2027** ([итоги](https://github.com/mikhalchankasm/NavisWorksMaster/issues/296)):
  - выпускаемый `NavisHelperSetup-2.12.0.0.exe` в тихом режиме обновил рабочую установку; плагин и MCP-сервер совпадают с пакетом файл в файл;
  - Navisworks загрузил плагин 2.12.0.0, `mcp_health_check` вернул `healthy` с сервером и плагином 2.12.0.0;
  - чтение (`list_item_children`) и запись (`clash_one_vs_rest`: 24 проверки и 25 наборов) работают при выключенном защищённом режиме.
- **Установщик в CI** (собран Inno Setup 6.7.1): чистая установка, обновление поверх старого сервера, удаление. Выпускаемый EXE собран Inno Setup 6.7.3. При сборке те же сценарии прошла тестовая сборка установщика на 6.7.3, а сам EXE вживую проверен тихим обновлением (см. выше).
- **Только сборкой:** версии 2024–2026, без живого прогона.
- **Не проверено вживую в этом релизе:**
  - страницы мастера установщика в обычном режиме;
  - подключение AI-программ флажком на последней странице;
  - установка расширения 2.12 в Claude Desktop;
  - защищённый режим во включённом состоянии с новой раскладкой кнопок и с новыми инструментами записи.

  Логика защищённого режима с 2.11.0.0 не менялась, изменилась только раскладка кнопок. Новые инструменты внесены в таблицу команд, которые при включённой защите требуют подтверждения; тест сверяет эту таблицу с тем, какие инструменты меняют документ.

## Ограничения

- AI worker и MCP-сервер, в том числе в `.mcpb`, требуют .NET 9 Runtime.
- Установщик не подписан. Windows может показать окно «Система Windows защитила ваш компьютер»: нажмите «Подробнее», затем «Выполнить в любом случае».
- Autodesk Interop берётся из установленного Navisworks.
- `selection_color_by_property` меняет постоянные цвета, которые `model_color_scheme reset` не отменяет.
- Наборы `clash_one_vs_rest` явные. Элементы, которые появятся в марке в новой версии модели, в проверки не попадут. После обновления модели вызовите инструмент заново с `overwriteExisting=true`, чтобы пересобрать наборы. Проверки с теми же именами при этом тоже заменятся: их результаты, группы и статусы пропадут. Если они нужны, сначала сохраните их или создайте новые проверки под другими именами (`setFolder`, `pairNameTemplate`).
- Флажок объединения составных объектов (Composite Object Clashing) в новых проверках `clash_one_vs_rest` не задаётся и остаётся таким, как по умолчанию в Navisworks.
