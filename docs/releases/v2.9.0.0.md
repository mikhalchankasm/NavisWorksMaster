# NavisHelper 2.9.0.0

## Основные изменения

- Завершена первая фаза локализации интерфейса: нейтральные ресурсы содержат английские строки, а русская локализация поставляется в satellite assembly. Добавлены ручной выбор языка и сохранение выбранного значения между запусками.
- Отредактированы английские формулировки интерфейса, чтобы команды, состояния и диагностические сообщения были короче и последовательнее.
- Исправлено использование устаревшего Clash cache при смене активного документа: данные Clash Detective теперь обновляются для текущего документа.
- Переработана интеграция OpenRouter с пользовательским API-ключом. В настройках доступны Connect, Disconnect и проверка ключа без перезапуска Navisworks.
- HTTPS-запросы к OpenRouter вынесены из `Roamer.exe` в отдельный framework-dependent процесс .NET 9 `NavisHelper.AiWorker`.
- Добавлен динамический пользовательский каталог моделей OpenRouter с поиском, точным выбором полного идентификатора и отображением возможностей модели. Каталог учитывает пользовательские provider preferences, privacy settings и guardrails.
- Для AI-окраски используется structured output со строгой схемой цветовых групп. Подтверждённый результат применяется к объектам непосредственно в Navisworks.
- Ошибка OpenRouter не маскируется скрытым локальным fallback. Локальная палитра остаётся отдельным явно выбранным действием и не выдаётся за результат AI.
- Production MCP-каталог сохранён на уровне 100 tools; имена инструментов, параметры и описания не изменены.
- Section Box capture/replay не входит в этот релиз.

Владелец подтвердил рабочий AI-сценарий на установленном bundle: подключение OpenRouter, загрузку и поиск в динамическом каталоге, выбор модели, получение structured color groups и применение цветов в Navisworks. Это не означает, что выполнен runtime smoke на всех поддерживаемых версиях Navisworks.

## Ограничения и требования

- Для framework-dependent `NavisHelper.AiWorker` требуется установленный .NET 9 Desktop Runtime либо соответствующий совместимый runtime .NET 9.
- Установщик не подписан Authenticode; Windows может показать предупреждение издателя.
- Autodesk Interop не включается в дистрибутив и загружается из установленной копии Autodesk Navisworks.
- Сборки для Navisworks 2024 и 2025 проходят build-validation, но отдельный runtime smoke для этих версий не заявляется.
- Для Navisworks 2026 и 2027 не заявляются проверки, которые фактически не проводились; подтверждён только описанный выше AI-сценарий владельца на установленном bundle.
