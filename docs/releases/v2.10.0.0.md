# NavisHelper 2.10.0.0

Релиз-кандидат после [2.9.0.0](https://github.com/mikhalchankasm/NavisWorksMaster/releases/tag/v2.9.0.0). В `main` зарегистрирован **111 MCP-инструмент** вместо 100. Исправление проверки окраски [#109](https://github.com/mikhalchankasm/NavisWorksMaster/pull/109) ожидает решения владельца и живой приёмки [#147](https://github.com/mikhalchankasm/NavisWorksMaster/issues/147).

- Добавлены перенос Clash-тестов (`clash_tests_export`, `clash_batchtest_import`), чтение Section Box и изоляция по зоне (`get_current_section_box`, `isolate_by_box`).
- Добавлены точная камера (`viewpoint_set_camera`) и мировые метки (`world_markers_set/list/manage`). Метки — временное наложение до 500 объектов: не сохраняются в модели, очищаются при смене документа и не обрезаются Section Box.
- Добавлены постраничное чтение результатов (`match_handle_items`) и асинхронное сохранение (`start_save_document`, `save_document_status`).
- Поиск различает элементы по идентичности, неоднозначные пути отклоняются. Подключение проверяет полный путь документа. Сокращены повторные обходы и чтения свойств; устаревшие handles объясняют отказ.
- MCP поддерживает `--read-only`; конфигуратор — ZCode. Настройка клиентов в EXE остаётся необязательной. CI проверяет ненулевое число выполненных тестов по TRX.

SHA кандидата, результаты CI, матрицы 2024–2027, ZIP/EXE smoke и хеши ассетов фиксируются в [#150](https://github.com/mikhalchankasm/NavisWorksMaster/issues/150). Сентябрьские хеши установщика к нему не применяются. Manifest содержит исходный коммит и подтверждение матрицы с хешами 12 DLL; повторная упаковка проверяет его. AI worker, MCP-сервер и конфигуратор публикуются заново. Подробности — в [правилах поставки](../MCP_DISTRIBUTION_PLAN.md).

ZIP smoke пишет во временный профиль; `--detect` читает конфиги клиентов без настройки. EXE smoke исключает реальные ярлыки и регистрацию деинсталлятора. Финальный кандидат ещё не проходил L3; исторические [измерения 107 из 111 инструментов](../MCP_TOOL_BASELINE.md) на Navisworks 2027 не заменяют проверку текущей сборки и версий 2024–2026.

Перед обновлением закройте Navisworks и MCP-сеансы. ZIP сохраняет `McpServer`, используемый прежним ZIP или EXE; настройте клиентов явно и сохраняйте каталог, пока он нужен EXE. При работающем сервере той же версии ZIP оставляет прежние файлы: завершите сеанс и повторите установку.

Framework-dependent AI worker и MCP требуют .NET 9 Runtime. Установщик не подписан; Autodesk Interop берётся из установленного Navisworks. `selection_color_by_property` меняет permanent-цвета, которые `model_color_scheme reset` не отменяет; apply по умолчанию очищает выборку. Публичный ZIP/EXE ещё не опубликован.
