# NavisHelper 2.10.0.0

Обновление после [2.9.0.0](https://github.com/mikhalchankasm/NavisWorksMaster/releases/tag/v2.9.0.0): **111 MCP-инструментов** вместо 100, новые операции с моделью и исправления проверки окраски и поставки.

- Добавлены перенос Clash-тестов (`clash_tests_export`, `clash_batchtest_import`), чтение Section Box и изоляция по зоне (`get_current_section_box`, `isolate_by_box`).
- Добавлены точная камера (`viewpoint_set_camera`) и мировые метки (`world_markers_set/list/manage`). Метки — временное наложение до 500 объектов: не сохраняются в модели, очищаются при смене документа и не обрезаются Section Box.
- Добавлены постраничное чтение результатов (`match_handle_items`) и асинхронное сохранение (`start_save_document`, `save_document_status`).
- Поиск различает элементы по идентичности, неоднозначные пути отклоняются. Подключение проверяет полный путь документа. Сокращены повторные обходы и чтения свойств; устаревшие handles объясняют отказ.
- MCP поддерживает `--read-only`; конфигуратор — ZCode. Настройка клиентов в EXE остаётся необязательной. CI проверяет ненулевое число выполненных тестов по TRX.
- `model_color_scheme` проверяет цвет с точностью `colorHex`: float-округление Navisworks больше не вызывает ложное предупреждение. При маскировке активного цвета предупреждение показывает запрошенный и прочитанный цвет; ошибки чтения остаются диагностикой. Reset сохраняет ранее заданные оттенки между шагами байта и восстанавливает очищенную выборку.

Manifest содержит исходный коммит и подтверждение матрицы 2024–2027 с хешами 12 DLL; повторная упаковка проверяет его. AI worker, MCP-сервер и конфигуратор публикуются заново. Результаты финальной сборки и проверки опубликованных ассетов фиксируются в [#152](https://github.com/mikhalchankasm/NavisWorksMaster/issues/152); SHA256 приложены к [релизу](https://github.com/mikhalchankasm/NavisWorksMaster/releases/tag/v2.10.0.0). Подробности — в [правилах поставки](../MCP_DISTRIBUTION_PLAN.md).

Живая [приёмка окраски #147](https://github.com/mikhalchankasm/NavisWorksMaster/issues/147#issuecomment-5946062851) прошла 2 октября 2026 года на Navisworks 2027: пять цветов по 100 объектов без ложных предупреждений, точное восстановление оттенка 0.5/0.5/0.5 и выборки, диагностика маскировки и ошибки native getter. Рабочий bundle восстановлен, модели не сохранены. Версии 2024–2026 проверены сборкой, без живого прогона; исторические [измерения 107 из 111 инструментов](../MCP_TOOL_BASELINE.md) не заменяют полную приёмку текущего релиза.

ZIP smoke пишет во временный профиль; `--detect` читает конфиги клиентов без настройки. EXE smoke исключает реальные ярлыки и регистрацию деинсталлятора.

Перед обновлением закройте Navisworks и MCP-сеансы. ZIP сохраняет `McpServer`, используемый прежним ZIP или EXE; настройте клиентов явно и сохраняйте каталог, пока он нужен EXE. При работающем сервере той же версии ZIP оставляет прежние файлы: завершите сеанс и повторите установку.

Framework-dependent AI worker и MCP требуют .NET 9 Runtime. Установщик не подписан; Autodesk Interop берётся из установленного Navisworks. `selection_color_by_property` меняет permanent-цвета, которые `model_color_scheme reset` не отменяет; apply по умолчанию очищает выборку.
