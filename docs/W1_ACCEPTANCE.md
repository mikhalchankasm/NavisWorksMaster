# W1 / NW-01: приёмка отзывчивости обходов

Срез включает инверсию выделения, изоляцию, «Показать всё» и выбор по
значению свойства. Семантика поиска свойств и раскраски сохраняется.

## Источник и статус

Primary продолжает неопубликованную работу внешнего разработчика из
коммитов `d552731`, `e703f2a`, `1c47c2b`. Его исходная ветка сохранена.
Передача через PR внешним разработчиком не выполнялась. PR Primary
служит единственным актуальным документом передачи и приёмки W1.

Исторические тесты и сообщения внешнего разработчика не подтверждают
поведение окончательной сборки. В частности, признак процесса `Responding`
не измеряет задержку вращения модели или обработки Cancel. Скрытие и показ
док-панели не доказывают уничтожение и повторное создание её экземпляра.

**Runtime-приёмка окончательной сборки пока не выполнена.** Merge возможен
после независимого review, проверок конечного SHA и принятой проверки
владельцем. Релиз и публикация установщика в этот срез не входят.

## Установка и привязка доказательств

1. Зафиксировать HEAD и чистоту исходников. Выполнить актуальные статические
   проверки, тесты и полную матрицу Release2024–Release2027, x64.
2. Владелец сохраняет работу и закрывает Navisworks обычным способом.
   Принудительное завершение процесса запрещено.
3. Сохранить копию установленного общего bundle, затем установить свежий
   bundle по `BUILD_BUNDLE_RULES.md`. Проверить SHA-256 DLL, Contracts и
   satellite assemblies всех четырёх версий.
4. Владелец запускает нужный Navisworks и открывает согласованную тестовую
   копию модели. Зафиксировать версию host, PID, путь действительно
   загруженной `NavisHelper.dll` и её SHA-256. Совпадения файла на диске
   без проверки загруженного модуля недостаточно.
5. Для каждого прогона записать SHA, версию, условный идентификатор модели
   («малая»/«крупная»), время запуска, наблюдения владельца и строку
   `ModelScan` из локального журнала. Клиентские имена, пути и снимки модели
   в публичный PR не включать.

## Шаги владельца

Начать с Navisworks 2027 и малой модели, затем повторить на крупной.
До отмены запомнить исходное выделение и скрытые объекты.

| Сценарий | Действия | Ожидаемый результат |
| --- | --- | --- |
| Инверсия до конца | Модель → выделить видимый объект → Инвертировать | Правильное новое выделение; фазы подготовки, обхода, проверки и применения понятны; нет ложного завершения до применения |
| Ранняя отмена | На большом выделении начать инверсию; Cancel во время подготовки | Прогресс закрывается; сообщение об отмене; исходное выделение/видимость сохраняются |
| Отмена обхода | Запустить инверсию и Cancel во время обхода | Те же гарантии, Busy освобождён |
| Поздняя отмена | После обхода нажать Cancel во время проверки исходного выделения | Сообщение именно об отмене; новое выделение не применяется |
| Повторный запуск | Сразу после отмены повторить инверсию до конца | Операция запускается и завершается |
| Отзывчивость | Во время подготовки/обхода/проверки вращать и панорамировать модель, переключить вкладку | UI отвечает; зафиксировать заметные задержки и максимальную длительность порций из журнала |
| Изоляция и показ | Смешанная исходная видимость; изоляция с отменой и до конца, затем «Показать всё» с отменой и до конца | Отмена сохраняет исходное состояние; завершение даёт правильную видимость |
| Выбор по свойству | Выбрать объект с поддерживаемым System/Special/Mark-свойством; выполнить выбор и отмену | Корректный результат; отмена сохраняет исходное выделение; пустой префилл без поддерживаемого свойства не является дефектом W1 |
| Изменение источника | В подготовке/обходе/проверке изменить выделение либо сменить документ | Старый результат не применяется, следующий запуск работает |
| Жизненный цикл панели | Во время подготовки и обхода закрыть/открыть панель; отдельно проверить реальный unload/dispose/recreate | Старый результат не применяется; подписки и Busy очищаются; новая панель работает |

Применение результата остаётся синхронным вызовом Autodesk на UI-потоке.
Отмена принимается до его начала; возможность отмены внутри этого вызова
не обещается. `applyMs` — длительность конкретного измеренного вызова, а не
гарантированный предел для других моделей.

При ошибке применения выполняется компенсационное восстановление: исходное
выделение либо флаги видимости всей модели, включая связанные экземпляры.
Затем состояние повторно читается небольшими порциями. Cancel после начала
изменений не прерывает восстановление; смена документа его останавливает.
Исход с ошибкой всегда остаётся ошибкой: сообщение различает подтверждённое
восстановление и неизвестное, возможно частичное состояние. Отказ самих
вызовов восстановления не позволяет обещать безусловный откат. Дополнительная
память снимка видимости линейна по числу элементов; измерить её влияние на
крупной модели. Проверка ошибок должна включать связанные экземпляры и
смешанные исходные флаги родителей/детей.
