Что изменилось

оставлено состав не тронут · перегруппировано · сокращено
  • сокращеноПамять выборки. Было 10 кнопок (Save S1–S5 + Recall 1–5). Стало одна ячейка: «Запомнить» / «Вернуть» + индикатор. По твоему замечанию: за сессию почти всегда нужна одна быстрая выборка.
  • перегруппировано«Выделение». Свободные кнопки «Копировать имена» и «Filter by list» собраны в группу Операции с выборкой вместе с Invert / Isolate / Unhide / Select by Property. Дерево разнесено на «вверх/вниз/вбок» (Parent/Child/Sibling) и «вглубь» (Leaf/All Under).
  • перегруппировано«Цвета». Ровные группы: Окраска → Match Color → Перенос цветов → История. «Reset all overrides» вынесен как нейтральная (серая) кнопка под окраской.
  • оставлено«AI». Остаётся отдельной вкладкой. Состав тот же, упорядочены секции: Модель → Схема → Применить → Ответ.
  • перегруппировано«Виды». Разделено на «Разметка вида», «Точки обзора», «Section Box». Длинные подписи укорочены.
  • оставлено«Данные». Импорт / Экспорт — без изменений по составу.
  • перегруппировано«Коллизии». Две таблицы регулируются по высоте видимым сплиттером с грипом (позиция запоминается). Панель групп A/B/Состав получает вертикальный сплиттер (ширина). Весь нижний блок настроек+действий свёрнут в Expander «⚙ Настройки и действия» — свёрнутый отдаёт таблицам всю высоту.
  • перегруппированоГорячие клавиши ушли в компактный блок‑подсказку внизу вкладки (раньше — крупный серый текст).

Кнопка ⋯ в шапке — командная палитра / overflow (как сейчас, Ctrl+Shift+P).
