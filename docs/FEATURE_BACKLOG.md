# Бэклог функций NavisHelper

## Кратчайшее расстояние между объектами

Статус: прототип снят с пользовательского интерфейса. Вместо него используется
предсказуемая функция высотных отметок по `Max Z` габаритного бокса.

### Как работал прототип

Пользователь выбирал один опорный объект и несколько измеряемых объектов.
NavisHelper по очереди запускал внутреннюю команду Navisworks
`MeasureShortestDistance`, преобразовывал каждое измерение в штатные redline и
сохранял все размеры в одной точке обзора.

### Почему функция отложена

- кратчайшее расстояние не является высотой и может пройти по диагонали или между
  ближайшими боковыми гранями;
- внутренний API измерений доступен только через нестабильную рефлексию;
- пакетная обработка была медленной и могла завершаться ошибкой после первого
  измерения;
- для высотных отметок нужен однозначный источник: верх объекта по габариту и
  глобальная координата Z.

### Когда стоит вернуться

Функция полезна как отдельный инструмент проверки зазоров и минимальных просветов,
но не как высотный маркировщик. Перед возвратом потребуются:

1. отдельный сценарий интерфейса «опорный объект + измеряемые объекты»;
2. проверка штатного API или устойчивой альтернативы внутренней команде;
3. пакетные живые тесты в Navisworks для всех поддерживаемых версий;
4. понятное отображение частичных ошибок и возможность повторить только
   неудачные измерения.
