# Удаление блока «Операции с выборкой»

08.09.2026 владелец решил убрать из NavisHelper весь блок: инверсию,
изоляцию, «Показать всё» и выбор по значению свойства. Сейчас эти команды
не имеют практического приоритета; инверсия дублирует штатную возможность
Navisworks. Доработка и дальнейшая runtime-приёмка W1 прекращены.

Удалены кнопки, регистрации палитры, обработчики, отдельные строки RU/EN,
идентификаторы иконок и оставшиеся без потребителей обходы модели. Новый
кооперативный механизм W1 и его специализированные тесты также исключены:
после удаления всех четырёх команд активных потребителей у него нет.
Закомментированные обработчики и архивные копии исходников не оставлены.

Навигация по дереву, память выделения, поисковые наборы, размеры выборки,
копирование имён, фильтр списка и раскраска продолжают работать через свои
существующие обработчики. Отдельные MCP-инструменты выбора и видимости
не входят в это удаление.

## История и возможное восстановление

Последний сохранённый кандидат W1 до удаления:
`f3a338c9d201d5f67576e955ce9133be6cb5678d` в истории PR #15.
Он включает переданную работу внешнего разработчика и исправления Primary.
Его автоматические проверки прошли, но runtime-приёмка не завершена.
На предшествующем `af42463` владелец обнаружил ошибку инверсии вложенного
объекта: выбор предка повторно включает исходный объект. Ошибка не считается
исправленной в архивном кандидате; активная функция удалена.

При новой практической потребности сначала согласовать конкретный сценарий,
проверить штатные возможности Navisworks, затем переносить нужный код из Git
в отдельную задачу с новой проверкой. Не возвращать весь блок автоматически
из старых макетов или старого PR и не считать прежние сборки принятой функцией.
