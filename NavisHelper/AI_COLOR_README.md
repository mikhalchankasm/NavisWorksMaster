# AI-раскраска через OpenRouter

Команда `AIColorObjects` получает цвета через отдельный .NET 9 worker
`NavisHelper.AiWorker.exe`. Процесс Navisworks не выполняет HTTPS к OpenRouter.
Worker получает versioned JSON-запрос через stdin и возвращает один typed
JSON-ответ через stdout. Старый `ColorService.exe`, временные JSON-файлы и
локальная подмена результата в рабочем пути не используются.

## Подключение

1. Откройте вкладку **Настройки** и раздел **AI**.
2. Получите ключ по ссылке **Получить ключ OpenRouter**.
3. Вставьте ключ в защищённое поле и нажмите **Подключить**.

NavisHelper проверяет ключ запросом `GET https://openrouter.ai/api/v1/key`.
Только после успешной проверки ключ сохраняется в пользовательской переменной
Windows `OPEN_ROUTER_NW_KEY`, добавляется в окружение текущего процесса и
становится доступен команде без перезапуска Navisworks. Значение ключа не
сохраняется в `ai_config.json`, не выводится в UI или журнал и не передаётся
через командную строку, protocol JSON, stdout/stderr, временный файл либо буфер
обмена. Для каждого worker ключ задаётся только в окружении дочернего процесса.

Кнопка **Отключить** удаляет эту переменную только из профиля текущего
пользователя и текущего процесса.

`OPEN_ROUTER_NW_KEY` хранится Windows как обычная пользовательская переменная
окружения (`HKCU\Environment`) и копируется в окружение текущего процесса.
Это не защищённое хранилище: значение доступно другим процессам того же
пользователя. В `ai_config.json`, UI-статусы и журнал ключ не записывается.

## Динамический каталог моделей

После подключения NavisHelper загружает пользовательский каталог через
`GET https://openrouter.ai/api/v1/models/user`. Список не содержит встроенных
рекомендаций: UI показывает только модели, для которых каталог подтверждает
`structured_outputs` и не запрещает текстовый output. В списке отображаются
имя и точный полный ID; произвольный ID ввести нельзя.

Сохранённый полный ID восстанавливается только при наличии совместимой модели
в свежем каталоге. Иначе NavisHelper предлагает выбрать модель и ничего не
выбирает автоматически. Недоступный каталог, отсутствующая, исчезнувшая или
несовместимая модель блокируют платный chat-запрос. Кнопка **Обновить модели**
повторно загружает каталог. Отключение очищает каталог и состояние готовности.

## Выполнение команды

Команда передаёт OpenRouter имена выбранных объектов и название выбранной
цветовой схемы. Запрос требует строгий `json_schema`: корневой объект содержит
только массив `colors`, а каждый элемент — только точное исходное имя `object`
и RGB-строку `color`. Ответ принимается только при наличии корректного цвета
для каждого точного имени без пропусков, дублей и лишних результатов. При
ошибке API или неполном ответе объекты не
перекрашиваются и локальный результат не выдаётся за AI-ответ.

Плагин сразу возвращает управление Navisworks: worker IPC и сетевой запрос
выполняются асинхронно вне UI-потока. Выделение, отображаемые имена и настройки снимаются
до первого `await`; применение выполняется через UI dispatcher только после
проверки, что активен исходный документ. Одновременно разрешена одна операция.
Смена документа, закрытие панели и пользовательская отмена останавливают
операцию; общий timeout составляет 90 секунд. При отмене завершается только
worker конкретного запроса, после чего single-flight coordinator допускает
следующий запуск.

Кнопка **Применить локальную палитру** — отдельное явное действие без сети.
Она никогда не запускается автоматически после ошибки OpenRouter. В результате
всегда показываются источник (`OpenRouter` или `Локальная палитра`), model ID и
число применённых объектов/групп. При смене языка уже показанный результат
переформатируется из семантического состояния.

Геометрия модели, API-ключ и другие свойства объектов в prompt не входят.
Reasoning в workflow раскраски не используется. `temperature` и рассчитанный
по числу имён output budget передаются только при заявленной поддержке модели.
За один запуск отправляется не более одного chat-запроса; автоматических retry
и разбиения на несколько платных запросов нет. Лимит составляет 200 уникальных
имён.
Стоимость запроса определяется выбранной моделью и тарифами OpenRouter.
Короткое предупреждение о передаче отображаемых имён размещено непосредственно
на вкладке AI.
